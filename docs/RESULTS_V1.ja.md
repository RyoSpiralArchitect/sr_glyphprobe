# GlyphProbe v1 実験結果

[English](RESULTS_V1.md)

## 結論を先に

固定した GPT-2 / FP32 / `resid_post` 条件では、絵文字由来の方向が、ランダム方向より再現性の高い出力指紋を示す候補が得られました。標準実験は14,208件の介入をエラーなしで完了し、実装済みの前因果的レディネス検査11項目と、アーティファクト整合性監査15項目をすべて通過しています。

これは集約レベルのスクリーニング結果です。36セルのうち11セルは、ランダム方向に対する指紋優位量がゼロ以下でした。したがって、結果は「全条件で一様な効果」ではありません。絵文字の意味、意味表現、回路、因果経路も特定していません。

## 1. MLX を採用した条件

### 固定セル

| 項目 | 値 |
|---|---|
| モデル | `openai-community/gpt2` |
| リビジョン | `607a30d783dfa663caf39e06633721c8d4cfcd7e` |
| dtype | FP32 |
| 介入点 | `resid_post` |
| レイヤー | 2 / 4 / 7 / 9 |
| 比較 | MLX/GPU と Transformers/MPS |

パリティ検証は、4種類のプロンプト長（3 / 9 / 10 / 22トークン）と4レイヤーを組み合わせた16セルで行いました。各セルでは、次の項目を確認しています。

- トークンIDの完全一致
- 基準ロジットと各 `resid_post` 活性化の一致
- ゼロベクトル介入が活性化とロジットを変えないこと
- 固定した非ゼロベクトルに対する活性化差分とロジット差分の向き・大きさ
- 介入後のargmax一致

検査は80 / 80項目が合格しました。記録時のエンドツーエンド集約中央値は、Transformers/MPS の 17.517 ms に対して MLX は 10.727 ms、速度比は1.633倍でした。計測にはトークン化、活性化の取得と介入、デバイス評価、NumPyへの転送を含みます。絶対時間は実行時の負荷にも左右されます。

このレシートが認めるのは、固定した GPT-2 / FP32 / `resid_post` セルでの一致と速度差だけです。別モデル、別リビジョン、量子化モデル、別dtype、別フック点へは一般化しません。

## 2. 標準スクリーニングの設計

| 項目 | 値 |
|---|---:|
| 一次グリフ | 10（5色 × 2形状） |
| ソースラッパー | 16 |
| ターゲットプロンプト | 24（6群 × 4） |
| ソース方向シード | 3（101 / 211 / 307） |
| レイヤー | 2 / 4 / 7 / 9 |
| 正の介入強度 | 0.025 / 0.05 / 0.10 |
| ランダム方向 | 各レイヤー2本 |
| 介入レコード | 14,208 |
| エラー | 0 |

ターゲットは classification、continuation、factual、planning、procedural、reasoning の6群に分かれます。ゼロ介入、汎用絵文字方向、パネルが張る部分空間に直交するランダム方向、符号反転、用量反応、ターゲット内ラベル置換を同じ計画に含めました。iso-KL と SAE は無効にしています。

14,208件の標準パイプラインを完走したのは MLX だけです。Transformers/MPS との比較は、固定したプロンプト、レイヤー、介入ベクトルを使ったバックエンド検証であり、標準実験全体を二重に実行したものではありません。

レディネス検査は11 / 11項目が合格しました。この検査は「次の因果実験へ進む価値があるか」を判断する内部ゲートであり、因果主張を許可するものではありません。レシートでも `causal_claim_authorized: false` のままです。

## 4. 効果は一様ではない

集約中央値だけでは、条件ごとの差を隠してしまいます。

- 36セル中、指紋優位量が正だったのは25セル（69.4%）
- 11セルはゼロ以下
- セル最小値は -1.219、最大値は 2.502
- レイヤー別中央値は、L2 = 0.868、L4 = 0.614、L7 = 0.365、L9 = 0.420
- シードをまとめた12セルでは、12 / 12セルが正で、中央値は0.931

ランダム方向の分離度は分布が広く、セルごとの変動も大きい状態でした。最大セルを代表例にせず、全セル中央値、シード横断集約、非正セルの数を併記します。現段階で堅く言えるのは、「固定条件の集約では再現性候補が見えるが、条件依存性も大きい」というところまでです。

## 5. トークン化の留保

一次グリフ10個はすべて3トークンで、16個のソースラッパーでも総トークン数はそろいました。一方、トークン列そのものは10個すべて異なります。`blue_circle` は中間トークンの接頭パターンがほかと異なり、中立グリフ `·` は1トークンです。

長さをそろえただけでは、字句構成の交絡は除けません。とくに中立対照との比較には、1対3のトークン長差が残っています。Phase I では、トークン数と接頭パターンをそろえた対照を追加します。

## 6. 統計上の留保

- 3つのシードは、ソース方向を作り直した反復推定です。独立した観測個体ではありません。
- 主な標本単位は24件のターゲットプロンプトです。プロンプトは6群にまとまっているため、独立同分布の24標本とはみなしません。
- ラベル置換値 `1/1001` は、1,000回置換で到達できる有限の下限です。真のp値がそれ以下だとは区別できません。
- 36セルを横断する多重比較補正や、プロンプト群を反映した階層推論は未実施です。
- 同じデータで選んだ最大セルを、確認的結果として扱いません。

## 7. 未実施の実験

今回の標準実験には、次の項目を含めていません。

- iso-KLで出力変位量をそろえた比較
- SAE特徴空間での測定
- 生成文への影響
- `resid_pre`、`attn_out`、`mlp_out` の介入
- コンポーネントパッチング、パスパッチング
- アブレーションと復元
- 独立ターゲット集合、別チェックポイント、別モデルでの追試

これらを経るまで、「意味を表す」「回路を見つけた」「因果経路を同定した」とは記述しません。

## 8. 公開アーティファクト

公開用バンドルには、パリティレシート、標準実験の要約、レディネス、指紋・用量反応・符号反転の集約、トークン化記録、アーティファクト整合性監査、ハッシュ付きマニフェストを収録します。

約74 MiB（77.3 MB）の `interventions.jsonl` とNPZは、公開リポジトリの容量を抑えるため収録しません。省略を隠さず、マニフェストに対象とハッシュを残します。完全な生台帳は、固定設定からローカルで再生成できます。

## 9. 現時点の主張

> 固定した GPT-2 / FP32 / `resid_post` 条件では、絵文字由来方向の出力指紋がランダム方向対照を上回る前因果的候補を、集約レベルで再現した。効果はセル間で不均一であり、意味表現、回路、因果経路はまだ確立していない。

この一文が、現時点での主張上限です。
