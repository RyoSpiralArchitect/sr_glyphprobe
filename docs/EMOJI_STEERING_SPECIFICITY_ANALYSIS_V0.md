# Emoji Steering Specificity Analysis v0 — T13-EA

[日本語](EMOJI_STEERING_SPECIFICITY_ANALYSIS_V0.ja.md) · [Acquisition protocol](EMOJI_STEERING_SPECIFICITY_HARVEST_V0.md) · [Question map](EMOJI_STEERING_SPECIFICITY_ATLAS_V0.md)

Status: **prospective, outcome-blind exploratory analysis contract**.

T13-EA analyzes the fixed T13-EH harvest. It does not add model forwards,
generation, protected targets, or a confirmatory decision. The contract was
fixed before response-ledger metrics, activation values, logits, or scientific
rankings were opened.

## Scientific-open boundary

Scientific values remain closed until one process verifies all of the
following:

1. the exact nine-role directory tree is complete;
2. all 198 receipts and 954 receipt-bound payloads occupy their registered
   paths with no extra files, symlinks, path traversal, or incomplete stage;
3. every baseline, source, and response artifact has its registered filename,
   dtype, shape, and row count;
4. all declared SHA-256 digests are independently recomputed;
5. a canonical run-binding root is written outside the run tree; and
6. the acquisition producer is no longer active.

The external closeout binds each allowed relative path, byte count, and
SHA-256 digest. An analyzer must re-audit that closeout in the same process
before it reads a scientific value.

Immediately after opening, and before any nonzero intervention row is analyzed,
the three pilot roles must pass the exact zero-hook gate. KL, JS divergence,
total variation, logit-delta RMS, top-tail values, and CountSketch must all be
zero; baseline/intervened entropy and argmax must agree. A failure stops every
scientific family.

## Fixed output families

### F1 — Item source-form contrasts

The fixed item intervention uses depth fraction 0.50, magnitude 0.25, both
signs, all 32 public targets, and the three pilot roles. Contrasts are paired
within model, item, target, and sign.

- Glyph minus Unicode name uses all 192 items per model.
- Glyph minus decomposed form uses the 168 non-atomic items per model.
- Unicode name minus decomposed form uses the same 168-item population.
- Missing atomic decompositions are structural missingness and are never
  imputed.

Intervals, when produced, use the prospectively fixed paired item-by-target
cluster bootstrap. Model roles are reported separately.

### F2 — Prototype depth and dose surface

Every registered model × glyph system × available source form × target ×
depth × magnitude × sign cell is retained. Full point surfaces are descriptive;
they are not a layer-selection device.

For nonnegative scalar endpoints, dose ordering uses the raw endpoint and sign
pairs measure magnitude symmetry. For signed entropy change, dose ordering uses
`sign × entropy_change`, and scalar antisymmetry is evaluated only on entropy
change. CountSketch sign reversal belongs to F5. Nonnegative divergence or RMS
cannot establish directional sign reversal.

### F3 — Positive isotropic random calibration

The random arm contains positive-orientation standard-normal directions only.
Registered random calibration therefore applies only to positive prototype
arms at the same model, target, normalized depth, and magnitude. Negative
prototype rows remain in the complete surface but are not described as having
a sign-matched random null.

The null is norm-matched after the imposed unit-RMS scaling. It is not matched
to activation covariance, the activation manifold, or a negative orientation.

### F4 — Target sensitivity

Baseline target entropy and the top-two logit margin are computed from the
stored baseline logits. Each intervention grid is first reduced to one response
profile per target; grids with different row counts are not pooled. Spearman
associations and target-group heterogeneity are sensitivity diagnostics, not
source specificity.

### F5 — Output direction

CountSketch vectors and top-token IDs are compared only within one model.
Cosine normalizes at comparison time and is undefined for a zero-norm sketch.
Top-positive and top-negative arrays are rank tails, so their observed sign
purity is reported rather than assumed.

Sign-paired rows report `cos(S+, -S-)` and swapped-tail overlap. Cross-model
analysis may compare scalar condition rankings on logical keys; it must not
compare vocabulary IDs or sketch buckets directly. Random seeds are
role-namespaced and cannot be aligned row by row across models.

### F6 — Source geometry

The complete nine-role source bank reports within-model source-form cosines,
wrapper dispersion, fixed eight-depth trajectories, and tokenizer count-
signature strata. Stored directions are first checked against the independent
mean of the four wrapper deltas.

The tokenizer preflight stores token counts and count signatures, not exact
token-ID or prefix sequences. T13-EA may therefore say **count-signature
matched**, but not exact-token matched. Raw hidden vectors are never compared
between model roles.

## Execution stages

The analysis is deliberately split into two nonadaptive stages:

1. deterministic integrity checks and complete-family point derivation; and
2. the registered 20,000-replicate bootstrap, executed in deterministic chunks
   and merged by sorted chunk ID and SHA-256 manifest.

Point estimates may be inspected before the bootstrap finishes, but they do
not acquire confidence intervals retroactively. Paper-facing intervals remain
blocked until every registered chunk and the deterministic merge validate.
No outcome may select a family, role, glyph system, target group, depth,
magnitude, sign, or endpoint for rescue.

## Interpretation boundary

T13-EH normalizes source directions to unit RMS before applying target-
activation scale. Its outcomes concern orientation under that imposed scale,
not natural encoding strength or source efficiency.

The available controls are Unicode names, decomposed forms where available,
positive isotropic random directions, and zero directions. T13-EH does not
contain matched ordinary text, matched non-emoji Unicode, or orthogonalized
random controls. Even a large, orderly result can support only exploratory
intervention-distribution differences relative to those fixed controls in the
three pilot roles. It cannot establish emoji meaning, unique emoji
specificity, behavioral generation effects, a mechanism, tokenizer
independence, a scale law, model-population generality, or confirmation.

Every null, heterogeneous, structurally missing, and failed cell is retained.
T13-C, if pursued, requires a new untouched target bank and a new freeze;
T13-EH observations cannot enter its confirmatory statistic.
