## 重要な境界：マージンと検索順位は分かれた

単語top-1の平均効果は、glyph情報の絶対的な低下・回復と、位置対照との差としての回復で
ちょうど**0**だった。位置対照との差としての低下はtop-1単位で−0.001282、全接頭位置
置換の校正は0.010256だった。これは記述的な平均であり、同等性検定ではない。
主要評価で確認できたのは、対応語との相対的な類似度の変化である。glyph情報の介入に
対応する平均top-1改善は観測されなかった。生成応答や下流タスクは試していない。

T21では非emoji記号に同じ経路介入をしていないため、絵文字固有の仕組みとは言えない。
完全・唯一の回路、自然文脈への一般化、無条件の必要十分性、生成のsteering、モデルを
またぐ因果再現も主張しない。コードポイント表記による残差置換、二文脈、固定ドナー・
ギャラリー、1チェックポイントに条件づく。接尾位置対照はattentionの重みや意味内容を
揃えてはいない。区間は適格性で定まる残余集団に対する近似的な項目再標本化モデルの
ものであり、すべての絵文字やドナー母集団の推定ではない。

## Compactな統計計算を再実行する

リポジトリと匿名資料には、195項目すべての5つの主要margin比較値と対応するtop-1比較値を
`item_contrasts.json`として含める。NumPyを導入した環境で、いずれかのrootから実行する。

```bash
python3 scripts/validate_t21_compact_inference_v0.py \
  --compact validation/t21_glyph_context_path_confirmation_v0/results/item_contrasts.json \
  --result validation/t21_glyph_context_path_confirmation_v0/results/confirmation_result.json
```

別の統計実装で、20,000回の再標本化による臨界値、5つの平均と下限、top-1平均、判定を
再現し、記録した環境での最大数値誤差は0だった。これは派生スカラー比較値からの推論を
検査する。上記の生の状態からの介入再構成は別の検査であり、省略したモデル依存配列を
必要とする。
