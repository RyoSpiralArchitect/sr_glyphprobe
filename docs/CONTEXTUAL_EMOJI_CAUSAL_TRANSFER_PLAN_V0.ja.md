# 絵文字の情報は、いつモデルの応答を変えるのか？

[English](CONTEXTUAL_EMOJI_CAUSAL_TRANSFER_PLAN_V0.md)

状態：**設計上の選択肢。事前登録・凍結・実行はいずれも未実施**。
作成日：2026-10-07。本書は独立した後続研究の案であり、モデル実行を許可するものでも、
過去の判定を変更するものでも、確認実験用データセットを提供するものでもない。
新しいモデル結果は報告していない。

## 提案する中心的貢献

絵文字の情報が通常のモデルの応答分布を文脈に応じて変えるか、また、絵文字位置を
送信元とする指定した注意経路がその変化に因果的に寄与するかを検証する。
CLDRラベルから独立した自然言語の応答候補、介入前の自然状態、通常の出力ヘッドを使う。
対象は限定された経路の寄与であり、完全な回路、人間同様の理解、学習データでの共起に
依存しない知識ではない。

[T21](T21_GLYPH_CONTEXT_PATH_RESULTS_V0.ja.md)が示したのは、読出し状態をcodepoint側の
状態へ置換した後の、keyword cosine marginへの条件付き寄与だった。絵文字メッセージの
絶対的な減弱・復元によるtop-1効果は平均ゼロだった。今回は、そのリセットを行わず
応答出力につながる介入を行うことが前進に当たり、keyword retrievalの別版を目指さない。

文脈依存の絵文字解釈自体は新規の貢献ではない。
[EMODIS](https://arxiv.org/abs/2511.07193)は、曖昧な絵文字を含む文、解釈を分ける対照的な
文脈、文脈に関する質問を用いたbenchmarkを既に記述している。本案ではarXivの要旨と
AAAI2026採択の注記を確認したが、手法の全文やデータは監査していない。差別化の候補は
機構と応答出力を結ぶ検証であり、文脈依存の絵文字評価を初めて行うことではない。
新規性の調査が完了したという意味でもない。

## 交差刺激と独立した妥当性の確認

各シナリオブロック`i`に、二つの文脈`c0, c1`、二つの絵文字`e0, e1`、有限で均衡した
自然言語の継続文候補対`Aij, Bij`（`j = 1,...,J`）を用意する。同一の継続文字列を
四つの交差入力すべてで採点する。同一文脈内の絵文字置換だけでは文脈依存性を示せない。
文脈の対照と絵文字の対照を両方残す。

文脈と継続文はCLDRラベルやモデル出力の好ましい傾向から導かずに作成する。候補数と
自然な表現を均衡させ、後で有利な言い回しを選ばず、少数の固定した言い換え集合を使う。
固定した集約値に加えて候補対ごとの結果も報告する。応答表現や提示方法は、該当する
範囲でカウンターバランスを取る。絵文字を省いた入力も残し、文章だけで答えがどの程度
決まるかを診断する。文脈のみで好成績になることも、モデルの成績が低いことも、
確認実験のブロックを事後的に除外する理由にしない。

意味に関する主張の前に、四つの入力と文脈のみの対照について独立した人間の判定を得る。
提案する最低人数は3名で、シナリオの作成者ではなく、モデル出力、想定した正解ラベル、
介入結果を見ない評価者とする。自然さと支持される継続文を評価し、「曖昧」「両方」
「どちらでもない」を選べるようにする。一致の基準はannotationの前に固定し、不一致、
不確実性、計画数・判定済み数・適格数の分母を残す。適格部分集合とcoverageを両方報告する。
不確かな例を無理に二値のgoldへ変えない。

人間の判定は、一方の文脈で好まれる答えだけでなく、意図した交差対照を支持する必要がある。
モデルによる選別の前に、この独立した対照から各ブロックの方向`eta_i ∈ {−1,+1}`を固定する。
この確認がなければラベルは**開発用ラベルのみ**であり、endpointは作成者の候補に対する
応答傾向を表すにとどまる。人間の解釈として妥当性が確認されたとは言えない。
人間の一致があっても、内部の意味が共通だと証明されるわけではない。

## 提案する出力対照の定義

入力`x_i(c,e)`と`T_y`トークンの継続候補`y`について、通常のteacher forcingで求める
系列対数確率を自然対数単位で定義する。

```text
ell_i(y | c,e) = sum[t=1..T_y] log P(y_t | x_i(c,e), y_<t)
s_i(c,e)      = mean[j=1..J] {ell_i(Aij | c,e) − ell_i(Bij | c,e)}
Delta_i(c)    = s_i(c,e1) − s_i(c,e0)
H_i           = eta_i * {Delta_i(c1) − Delta_i(c0)}
```

主要な採点規則は**候補の全トークンの対数確率の和**である。事後的な長さ正規化、
都合のよい先頭トークンだけへの縮約、有利な候補部分集合への置換は行わない。
prompt境界、tokenizerの扱い、chat/base形式、候補の句読点、EOSを含めるか、`J`を
確認実験前に固定する。候補の長さとtoken数の診断結果も残す。同じ候補を各セルで使うと、
候補や文脈の加法的な選好と交互作用を区別しやすくなるが、語彙的な交絡をすべて除ける
わけではない。四つの`s`と二つの`Delta`をすべて報告する。交互作用だけでは、どちらの
絵文字が効果を駆動したかは分からない。

行動上の推定対象は、固定した母集団とfamily重み付け規則における`H_i`の平均とする。
正答率、選択の反転、個別トークンの寄与、正規化していない候補確率は副次的な診断とする。
正の交互作用は非加法的な応答効果であり、それだけで特定の表象や回路の証拠にはならない。

## 自然状態からの経路交換

両入力を通常の無改変forwardから開始する。各文脈内で、もう一方の絵文字入力をdonorに
する。モデルごとに絵文字spanのtoken数と位置を一致させる。不適合な対の除外は、固定した
結果非依存のtokenizer規則で行い、分母を報告する。主要な交換は、固定した層窓とhead集合で、
絵文字の送信元位置のpost-RoPE keyとvalueを置き換える。残差streamのリセットやCLDR viewの
patchは行わない。

経路`G`の案は、その層窓における絵文字送信元から、因果的に後続する全query位置への
経路とする。prefix内の位置と、teacher forcing中に継続トークンを予測する位置を含む。
query範囲とcache実装を確認実験前に正確に固定し、最後のprefix tokenだけの経路と
全応答tokenの経路を黙って切り替えない。donorの送信元状態は、同じ文脈で絵文字だけが
異なる入力から得る。送信元位置では望ましい答えにアクセスできないようにする。
望ましい答えの残差状態は注入しない。

受信側が絵文字`ea`で、経路`G`だけdonor絵文字`eb`を使った通常の出力scoreを
`s_i^(a<-b,G)(c)`と書く。交換の両方向は分けて保持する。

```text
p_i^+(c,G) = s_i^(0<-1,G)(c) − s_i(c,e0)
p_i^−(c,G) = s_i(c,e1) − s_i^(1<-0,G)(c)
K_i^d(G)   = eta_i * {p_i^d(c1,G) − p_i^d(c0,G)}, d in {+,−}
Kadj_i^d   = K_i^d(G) − K_i^d(C)
```

`C`は別途固定した非絵文字位置の対照経路で、交換方向と受信側条件を揃える。
正の`K`は、交換が人間の判定で方向付けた文脈交互作用を予測方向へ運ぶことを表す。
`Kadj`は、この特定の位置対照を超える寄与があるかを問う。媒介割合ではない。
小さい、または符号が変わるclean/corrupt差で割って回復率を作らない。

モデル内の成功条件案は、実質的に正の行動効果`mean(H)`、**両方向**で実質的に正の経路効果
`mean(K^+(G)), mean(K^−(G))`、そして両方向で正の調整後対照とする。未調整の効果も要求する。
二つの負の効果の差が正でも、転送成功とはしない。実用上意味のある効果の閾値と、
同時推論の規則は確認実験前に固定する。相関したこれらの対照は一つの連言的検証であり、
5回の反復実験ではない。本書では閾値を設定せず、いずれの条件の達成も宣言しない。

## 対照と競合説明

- 実装：無効化したhook、同一状態donorの交換、復元・再生、同一のbatch構成。
  結果を見る前に許容誤差を定める。数値的な検査合格は科学的証拠ではない。
- 位置対照：同数の非絵文字spanを使い、注意量、送信元からの距離、メッセージのnormを
  記録する。対照の規則はpilotで選び、確認実験の効果で選ばない。donor間で同一になる
  絵文字より前のspanはno-op対照であり、有力な情報経路の競合対照ではない。絵文字より後の
  spanは既に絵文字情報を含む可能性がある。その効果は有用な競合説明であり、自動的に
  artifactとは扱わない。位置数を揃えるだけでは不十分で、残る不一致も報告する。
- 一般的な情報担体の対照：通常の語句と非絵文字記号による同型の交差課題を用意し、
  伝達上の役割、行動効果の余地、span数、位置を可能な範囲で合わせる。同じ経路介入を
  適用する。語句・記号でも同様の効果が出るなら、絵文字も扱う共通の機構を支持するので
  あって、絵文字特有の機構ではない。絵文字の優位を主張するには、担体間の明示的な
  交互作用と不確実性が必要であり、別々の有意・非有意の比較では不十分である。
- 校正：広い経路／全状態の自然donor交換と、無介入入力間の対照により、選んだendpointと
  siteで効果を検出できるかを確かめる。これらの交換は参照値であり、証明された上限ではない。
  一般的な流暢さや無関係な応答の悪化も報告し、広範な破壊を意味の転送と取り違えない。
- 機構：K/Vが固定した絵文字identityを表し、受信側Qだけが文脈に依存していても、文脈的な
  効果は生じうる。したがってK/V交換だけでは、絵文字位置に文脈固有の意味が保存されていると
  示せない。KとVの分離交換は、新しい主要な問いとして独立に固定しない限り副次扱いとする。

自然なdonor状態と無改変の開始状態を使っても、patch後の混合状態が分布内である保証はない。
この介入が検証するのは指定した反実仮想の計算であり、唯一の媒介変数やすべての間接経路を
特定するものではない。評価指標とcorruptionの選択には特に注意が必要である。
[Zhang and Nanda](https://arxiv.org/abs/2309.16042)は、こうした選択でpatchingの結論が
変わりうると報告し、[Heimersheim and Nanda](https://arxiv.org/abs/2404.15255)は解釈と
指標の落とし穴を論じている。本書で確認したのは両論文の要旨までであり、実装前には
関係する手法の全文を確認する必要がある。

## 小規模pilotから独立に凍結した確認実験へ

1. 複数の開発用familyにわたる24–32シナリオブロックを使う。debugと設計のpilotであり、
   確認実験ではない。まず既に存在する3B checkpointを一つ使い、実行前に正確なartifact、
   tokenizer、runtime、prompt形式を固定する。本書だけを根拠にdownloadやモデル実行をしない。
2. site探索を、例えば事前に宣言した最大3個の層窓に制限し、記録したpilot専用の規則で
   主要な層窓を最大一つ選ぶ。両方向の転送と、失敗を含むすべての計画済み対照セルを残す。
   annotationの実行可能性、自然baselineの効果の余地、位置合わせ、経路校正、family間の
   分散を調べる。条件を満たさなければ確認用データを消費せず、開発用材料を修正する。
3. 第1モデルの確認計画を、新しいtargetから独立に凍結する。確認標本数はpilotのfamily単位の
   分散、必要な精度・検出力、実質的効果の閾値、固定予算から求める。少なくとも20の新しい
   文脈・template familyという数は初期制約の案であり、**固定済み標本数でも検出力の保証でもない**。
   少数family内の言い換えを増やしても、新しいfamilyの代わりにはならない。
4. 別familyの7Bモデルでの再現を別途規定する。checkpointとtokenizerを正確に固定し、
   必要な実装・pilot検査を開発用材料で繰り返してから、確認用forwardの前に介入規則を
   独立に凍結する。正規化した層番号が等価な機構を表すとは仮定しない。第2familyでの再現は
   現象の再現であり、同じ回路の再現ではない。モデルをpoolして再現失敗を救済しない。

family依存を扱う推論を使い、familyと絵文字の再利用の扱いを固定する。絵文字IDがfamilyを
またいで繰り返されるなら、その依存をモデル化・resampleするか、主張を試した有限の
絵文字集合に限定する。familyごとの効果、計画済み・完了・失敗したすべてのセル、
不確実性を報告する。推定量、resampling方式、多重性を扱うfamily、欠測規則の詳細は、
登録前に解決すべき未決事項である。

確認用刺激をモデル出力に基づいて採用・除外・書き換えたり、有利な層へ割り当てたり
しない。人間判定とtokenizerの適格性規則は先に固定する。独立した管理者が新しい確認bankを
作成・封印することが望ましい。debugで露出したbankは、未露出の確認用bankとしては退役させる。
有意性に応じた適応的停止は提案しない。必要な標本数が予算を超えるなら、主張を狭めるか、
探索研究のままにする。

## 新規性の範囲、探索的拡張、結果ごとの分岐

従来のmatched poolは954の適格絵文字を含み、報告済みT19/T20/T21への割当てによって
使い切られている。新しい文脈は、新しい絵文字でも、新しいpretraining exposureでも、
未使用のglyph holdoutでもない。後続研究では新しい文脈familyと再利用する絵文字を区別し、
新しく構成する母集団を明示的に予約する必要がある。保護された歴史的target bankには
触れず、刺激作成・debug・設計調整の材料にしない。

同一tokenの文脈間状態転送は、任意の**探索的な副次実験**とする。同じ絵文字の状態を
異なる文脈間で共通のreceiverへ移す。通常の語句・記号の担体対照、位置合わせ、周囲の
文脈を複製しているだけではないかを調べる対照が必要になる。成功しても、絵文字が一般的な
文脈情報ではなく意味を保存していると、それだけで示せるわけではない。主要な結果を
見てからこの拡張を主要実験へ昇格させない。

| 結果 | 許される結論・次の行動 |
| --- | --- |
| 人間による妥当性確認が未達・未実施 | 開発用ラベルの分析に限定し、意味に関する主張の前に独立annotationを改善する。 |
| 自然状態の交差効果が実質的に認められない | このendpoint・母集団での文脈依存の絵文字効果は支持されない。確認bankから成功例を選ばず、刺激の仮説を再検討する。 |
| 自然な交互作用はあるが校正が不十分 | site／endpointはuncalibratable。関連表象が存在しない証拠にはしない。 |
| 自然な交互作用と十分な校正があるが方向性のある経路効果がない | 指定した経路の説明は支持されない。別経路や冗長経路は残る。 |
| 方向性のある変化と広範な破壊が併存、または位置対照を超えない | 特定経路の解釈は未解決。一般的な破壊を意味の転送と言い換えない。 |
| 経路寄与があり、一般的な担体でも同等の効果 | 絵文字も処理する共通の文脈情報経路を支持する。絵文字専用機構ではない。 |
| 一つのモデル、または露出済みtemplateのみで成功 | そのモデル・母集団に限定する。モデルfamily間や未使用familyでの成功を主張しない。 |
| 両モデルの独立した確認実験で固定条件を達成 | 試した二つの構成で、指定した文脈依存・出力接続型の経路寄与を支持する。表象と共起に関する限界は維持する。 |

実行前の未決事項は、作成者・評価者の運用、モデルartifact、刺激とfamilyの一覧、
実質的効果の下限、経路・対照mask、donor規則、標本数計算、推論計画である。
これらを凍結できるのは、後で明示的に定めるprotocolと実行の判断である。
