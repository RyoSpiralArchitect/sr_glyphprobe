by the frozen Milestone 2 protocol. It must not be represented or reused as an
untouched bank.

The C1 v1 bank is retired from future confirmatory and causal use. On

record in a research-agent context. No experimental model forward, tokenizer
pass, outcome analysis, panel selection, or endpoint selection used that
record. Nevertheless, the repository's stricter rule prohibited passing C1 to
any model context before a causal freeze. The bank can therefore no longer be
called fully untouched.

The exposed prompt is not reproduced in public documentation. The immutable C1
v1 file remains in place as historical evidence, but only content-blind
existence, size, and hash checks are permitted. A future causal experiment
requires a new versioned bank prepared outside the exposed research context.
