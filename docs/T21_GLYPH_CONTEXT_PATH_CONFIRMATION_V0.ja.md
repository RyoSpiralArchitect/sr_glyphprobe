# T21-C：glyph位置からの経路を未使用項目で確認する

[English](T21_GLYPH_CONTEXT_PATH_CONFIRMATION_V0.md) | [探索プロトコル](T21_GLYPH_CONTEXT_PATH_PILOT_V0.ja.md)

## 問いと範囲

読み出し位置の残差状態を同じ項目のコードポイント表記の状態に置換した後も、
glyph位置から届く後段のattentionの情報は、対応する単語とのコサイン類似度の差に
寄与するか。T20で使用済みの384項目によるT21探索で、事前に定めた規則が選んだ
**block 21の一候補**を確認する。T19・T20の主要評価項目や判定は変更しない。

残る195項目を再構成・トークン化する前に、この設計と実装をcommitする。
その後、確認実験のモデル実行に先立って入力を記録・公開する。これは時刻付きの
内部事前仕様であり、外部機関への事前登録を意味しない。

## 対象集団と保護する入力

元のCLDRキーワードとの一対一対応954項目から、T19の375項目とT20の384項目を
除いた**195項目すべて**をUnicode原資料の順で使う。効果による選別、結果を見ての
標本追加、結果に基づく除外は行わない。対照語とドナーにはT19の128項目を再利用し、
glyphのトークン数が同じドナーをハッシュ順で二つ選ぶ。「未使用」は今回までの
実験での未評価を指す。事前学習や過去の文章に登場しなかったことは保証しない。

固定済みのemoji-testとCLDRの原資料から、emoji側の対応だけを再現する。
既存の記録にある55個の記号用aliasを予約し、候補数と、**使用済み759項目すべての
alias対応の一致**を要求する。旧選択処理のリポジトリ全文走査は、再利用を禁じた
過去のターゲット集合も読むため実行しない。過去の文章への登場歴は再監査せず、
新たな文章上の未出現性を主張しない。件数、対応、トークン化、ドナー条件の不一致は
実行を止める。195という母数を暗黙に減らして続行しない。

## 介入と測定

モデルは探索と同一のLlama 3.2 3B BF16とし、実行環境、RoPE適用後のkey/value置換、
コードポイント表記による残差置換、同じバッチ位置の対照、二つのドナー、129候補の
固定ギャラリーも維持する。対象blockより後で、読み出しqueryが受け取る情報だけを
置換する。そのattention介入自体は他のqueryを変更しないが、下流の計算を通じて
影響が伝わることはある。

主要評価では**距離8**のpipe・articleの二文脈と二ドナーを項目内で平均する。
統計上の標本数は195であり、条件・文脈・ドナーを掛け合わせた行数ではない。
同じバッチ構造を保つためblock 24と距離4も取得するが、補助解析に限定し、
主要候補との入れ替えを禁じる。接尾位置の対照は位置数を揃えるものであり、
attentionの重み、位置、意味内容までは一致させていない。

E(条件)は単語マージンから、同じバッチ位置で経路置換だけを無効にした値を引いた差
とする。対照にも残差置換は残す。以下の五つを主要比較とする。

| 比較 | 定義 |
| --- | --- |
| 校正 | E(残差置換のみ) − E(全接頭位置ドナー) |
| 絶対的な低下 | E(残差置換のみ) − E(glyph位置ドナー) |
| 位置対照との差：低下 | E(接尾位置ドナー) − E(glyph位置ドナー) |
| 絶対的な回復 | E(全接頭位置ドナーから自身のglyphを復元) − E(全接頭位置ドナー) |
| 位置対照との差：回復 | E(自身のglyphを復元) − E(自身の接尾位置を復元) |

表内の各条件は残差置換を伴う。共通の条件を使う比較なので、五つの独立した再現実験
とは数えない。単位はコサイン類似度のマージンであり、**正答率のパーセントポイント
ではない**。全接頭位置置換の平均低下量に対する比率は記述的に示すが、それを普遍的な
上限や説明分散とは呼ばない。実用的なsteering効果や最小有用効果量は主張しない。
top-1検索正答率は別の補助評価とする。

## 多重性と判定

五つの平均に対する**片側・同時95%下限**を、項目単位のbootstrap 20,000回、
seed 2026092201で求める。五比較で同じ再標本化インデックスを使う。
各反復b・比較jについて z(b,j) = (再標本平均 − 元の平均) / 再標本標準誤差
を計算し、max_j z(b,j)の95パーセンタイルを臨界値とする。分位点は線形補間、
標準誤差は標本標準偏差 / sqrt(n)、同時下限は平均 − 臨界値 × 元の標準誤差とする。
標準誤差が退化した場合は判定を停止する。これは相関を保つsingle-step方式であり、
stepdownは実装しない。一般的な再標本化の枠組みは
[Romano and Wolf (2005)](https://doi.org/10.1198/016214504000000539)を参照する。

完全取得と実装検証に合格し、**五つの同時下限がすべて0を超えた場合だけ**肯定判定を
与える。校正が通らなければ経路の問いは未解決、校正が通っても他の比較が通らなければ
指定した組合せの主張は支持されない。途中の成功判定、候補の変更、補助評価の主要化は
行わない。区間の被覆は近似的で、固定ドナー集団と項目再標本化モデルに条件づく。
195項目は適格性で定まる残余集団の全数であり、すべての絵文字・言語・モデル・ドナー
集団への一般化は認めない。

## 未使用項目に触れる前の精度・品質点検

384項目の探索値は別実装で再計算し、保存した全指標が誤差0で一致した。
block 21では両文脈・両トークン長群で主要比較の平均が正であり、効果の大きい上位5%を
外しても全体の平均は正のままだった。これらは記述的な感度点検であり、追加の確認検定
や除外規則にはしない。

探索の共分散と臨界値を用いた195項目の模擬集団5,000組では、五比較の同時判定を
通る割合は、探索平均のままで99.9%、各平均から探索の標準誤差一つ分を引いて98.98%、
平均効果を半分にして60.5%だった。候補選択後の条件付き見積もりなので楽観的な可能性が
あり、検出力の保証ではない。確認実験では臨界値を改めて算出する。利用可能な全項目を
含め、この点検に合わせてnや判定閾値を調整しない。数値の記録は
`validation/t21_glyph_context_path_pilot_v0/results/precision_and_quality_report.json`。

## 実行と原稿への反映

設計・コードを公開し、新しい実行処理を使用済みの8項目で検証する。元のcanary状態の
bit単位の再現、標準attentionとの一致、同じバッチ位置での無操作・復元対照の完全一致を
要求する。その後に195項目を再構成・トークン化し、入力仕様を公開して一度だけ取得する。
GPU競合時には次の項目境界で譲り、他の処理を終了させない。同一仕様の未完了runだけ
再開できる。失敗の記録を残し、項目へのアクセス後に科学的設計を変えた実験を当初の
確認実験として扱わない。

別実装で指標・区間・判定が一致してから原稿に反映する。それまではTable 6修正版を
投稿用として保持する。肯定結果が支持するのは、**このモデルと介入条件における、
単語との類似度への後段attention経路の寄与**である。唯一の意味回路、絵文字に固有の
仕組み、生成のsteering、または以前の局所成分実験の肯定への転換は主張しない。
