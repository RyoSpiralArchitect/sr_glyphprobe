# 査読後の証拠補強計画 v0

[English](POST_REVIEW_EVIDENCE_PLAN_V0.md)

2026-09-02、新しい指標分解を計算する前に作成した。完了済みのT19/T20/T21を読解した
後に行う、**事後的な診断と再現性の検証**であり、新しい事前確認実験ではない。
既存のプロトコル、適格性、統計的判定、結果記録を変更しない。
新たなモデル実行や評価項目の選択は行わない。

## 1. T20の採用時点と訓練診断

保存した訓練履歴から、全27組のサイト・seedの採用チェックポイントを再構成する。
各seedではvalidation指標の最大値を最初に達成した時点を採用し、seed間では最大値、
同点なら小さいseedを選ぶ。採用時点と600ステップ目を分けて報告する。記録された
訓練損失はその反復の更新前のミニバッチ損失で、保存された基底は更新後のものである。
いずれも採用基底を訓練集合全体で測った値ではない。
主要サイトがuncalibratableという登録済み判定は保つ。

## 2. T21のマージン分解

確認実験の195項目すべて、元のblock 21、距離8の両carrier、指定済みの両donor、
同じ128項目のsource gallery、元の5対比すべてを用いる。保存状態から次を再構成する。

- 対応する自項目のkeywordとのコサイン。
- source keywordのうち最大のコサイン。
- gallery内の競合の診断として、注入donorのkeywordとのコサイン。

元の測定と同じく、自項目のkeywordを先頭にした129列の類似度を一度に計算する。
項目内で平均する前に、各条件から同じbatch位置のneutral参照を引く。
元の対比演算を各成分に適用し、自項目の対比から最大競合の対比を引くと、
元のマージン対比になることを項目単位で確認する。許容誤差は`1e-10`とする。
保存されたすべての文脈・anchorについて元のmargin、donor-margin、top-1の配列も
再構成し、誤差`1e-10`未満、top-1は厳密一致を求める。source、仕様、各chunk、
解析のチェックサムを先に確認する。

元の全対比について成分の記述的平均を報告する。成分の有意差検定、結果に応じた
項目除外、モデル・anchor選択、新しい閾値、二度目の確認判定は追加しない。
最大競合の項目は条件間で変わり得る。この分解は指標の恒等式であり、機構を独立に
分離するmediation解析ではない。donor類似度は加算可能な第三成分ではない。

## 3. T19のモデル不要な統計再計算

既存のprimary予測index、正確な局所stratum、項目順をコンパクトなJSONにする。
各source summaryを、公開済みの独立検証に記録されたhashおよび予測ファイルの
チェックサムと照合する。全9構成、両glyph種、両component、全24主要文脈を含め、
隠れ状態の再構成やbankのtokenizeは行わない。

独立したNumPyのみのプログラムで、36のrandomization検定、20,000回の記述的bootstrap
区間、モデルのintersection--union値、効果量条件、Holm判定、主要4構成の
partial-conjunction値を再計算する。元のseedと乱数の消費順を保つ。
`1/n`は一様な当て推量の基準であると説明し、matched randomizationの期待値は
予測先が対象項目のstratumに属するかに依存することを示す。

## 4. 表現と成果物

数値を検証してから、英文論文と日英のrepo文書を更新する。T21を本文の簡潔な図・説明
で伝え、全5対比の表と記述的分解は補遺に残す。本文9ページを維持する。
コンパクトな再計算入力・検証器を含む新しい匿名archive版を作り、既存版は保存する。
展開したarchiveを検証し、提出PDFを描画して確認する。

使用を終えた二つの歴史的target bankは開かない。新しい作業は、既に許可され完了した
T19/T20/T21の出力だけを使う。チェックサムは同一性を示すもので、正しさの証拠となる
数値再構成とは分けて扱う。
