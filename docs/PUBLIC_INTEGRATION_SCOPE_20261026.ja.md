# 公開Repoへの統合範囲 — 2026年10月26日

[English](PUBLIC_INTEGRATION_SCOPE_20261026.md)

## 目的と状態

この文書は、10月26日に`sr_glyphprobe`へ統合する資料の範囲を定めます。
元のリポジトリは現在publicであり、著者は公開状態を保ったまま、公開対象として
点検した資料だけを統合する方針を選びました。これは範囲の記録であり、テスト、
push、merge、新たな科学的実験の完了を示すものではありません。
実施結果は別途記録します。

10月15日のプレプリントは、引き続き
[Zenodo](https://doi.org/10.5281/zenodo.23376699)のversion 1.0.0です。
固定したPDF・資料集・準備時manifest・科学的な判定は、この統合では変更しません。
次版の計画も、新たな確認済みの結果とは区別します。

## 含める資料の種類

- 点検した研究実装、合成データによるテスト、著者作成の開発用入力、英日ペアの研究ノート。
- 公開済みのプレプリントと再現用資料集。元の照合値とライセンス範囲を保持します。
- 公開範囲を明記したデータの抽出物と集計報告。これらの提供は、省略した生記録の公開や、
  全ての過去実験の独立した再計算を意味しません。

対象パスを明示して追加し、未公開の開発ブランチの履歴を一括では持ち込みません。
正確な統合内容は、実際の追加ファイル一覧とコミットで特定します。
この種類別の一覧を、後から別のファイルを追加する許可として扱いません。

## 含めない資料の種類

- 著者の個別回答、割当、ラベルを隠した参加用パケット、回答履歴などの非公開参加者記録。
- 廃止・保護されたホールドアウトbankの内容。再読や再利用もしません。
- 実機固有の実行環境・ソース所在を含む生記録、プロセスやGPU使用状況の記録、運用上の引き継ぎ手順。
- モデル・トークナイザ本体、実行環境、キャッシュ、認証情報、ローカルのbuild・ブラウザ作業用ファイル。
- 点検していないノートブック、バイナリ成果物、過去の中間資料集。

実機のパスを隠すために、生成済みreceiptを直接書き換えることはしません。
移植可能な資料が必要な場合は、元の記録との対応を保持した公開用の抽出処理を用意します。
公開済みの適格性検査資料には、この形式の抽出物が既に含まれています。
元の準備状態は履歴として保持し、その後の公開・統合の記録と区別します。

## 検証の範囲

ローカルの対象回帰テストは**618件成功、52件スキップ、72 subtests成功**でした。
46件は除外したアーカイブを明示的に必要とし、6件は従来の取得記録の存在確認で
スキップされます。成功扱いにはしません。`tests/conftest.py`は対象テストだけを対応付け、
固定した科学的runnerやそのテストは変更しません。`--require-archive-evidence`を
渡すと新しい欠損時スキップを無効にでき、前提資料がなければ元の検査が通常どおり失敗します。

公開パッケージは、標準ライブラリだけでの整合性・保存スコア再計算を通過しました。
別出力先でのTectonic 0.17.0ビルドは36ページとなり、はみ出しと未解決参照はありません。
underfull警告は残っています。公開PDFと資料集のバイト列、統合の基点にあるT22の
ソース・設計・証拠ファイルは変更していません。
[生成した検証記録](../validation/public_integration_20261026/audit.json)に、対象ファイル、
テスト出力、buildログのハッシュを結び付けています。この記録はリモートへのpush・merge、
新たな科学的取得、ページ画像の再目視確認を示しません。

選んだ過去の機械的科学記録・集計30ファイルは、意図的に部分的な収録です。
仕様やruntime記録を除いているため、実行全体の再検証はできません。
元のバイト列と結論は保持しています。変更しない
`artifacts/public_release_20261015/`には、別経路として、公開保存スコアの再計算に
必要な資料が揃っています。

合成データによるテストとソース検査では、非公開の取得記録を参照せずに実装の性質を
確認できます。除外した過去の実行環境や生記録を必要とするテストは、公開範囲では
実行不能であることを明記します。これらを黙って持ち込んだり、検査を緩めたりして
成功扱いにはしません。公開した保存済みスコアの再計算が成功しても、示すのは資料の
整合性と記録済み得点の算術であり、新たなモデル実行や人による検証ではありません。

完了済みの明示的事実に対する適格性検査は4,640回のforwardを記録し、数値検査を
通過しました。一方、事前指定した直接質問・最小回答の要件と回答ラベルの要件は、
両方とも不合格でした。この科学的な否定結果は、ソフトウェアテストの成功とは別です。

今回の点検は新たに選んだ統合対象に限られます。公開Repoに既に存在する全ファイル・
コミット・外部成果物・過去の権利処理を、一括で保証するものではありません。
