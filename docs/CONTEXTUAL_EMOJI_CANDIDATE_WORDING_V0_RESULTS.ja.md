# 候補文の変更：正の交互作用と、候補選好の感度

**追加768スコアをすべて取得し、欠測は0だった。** Llama 3.2 3Bの同じ開発用24課題で、
絵文字の平均交互作用Hは3組の候補文すべてで正（1.196〜1.316）だった。一方、
高スコア候補の著者定義による肯定・否定の向きは、候補文の組を変えると絵文字52/96入力、
単語56/96入力で変化した。この測定では、正の交互作用と絶対的な候補選好の安定性を
区別して扱う必要がある。

これはteacher forcingによる系列採点で、生成実験ではない。追加候補は元の結果を
見た後に指定した。長さ・具体性・語彙・形態が同時に変わり、人による意味等価性の
検証もない。否定表現の単独効果、絵文字特有の意味曖昧性解消、因果性は確立しない。

## 全結果

s(c,v)=log P(A|c,v)−log P(B|c,v)。Hと平均の単位は自然対数。
「一致」は著者の提案ラベルとの一致であり、妥当性確認済みの正答率ではない。
交差はeta·delta_p < 0 < eta·delta_qを要求する。同点はなかった。

## 解釈と残る対照

パネル平均の交互作用は、試した候補文変更をまたいで残った。絶対的なラベル一致は
限定的で、集計の一致数が似ていても、個々の入力の選好は頻繁に変化する。
交互作用の大きさ・交差・絶対選好を分けて報告する根拠になる。各組の平均交互作用は
単語の方が大きく、family・項目間の異質性もある。一般的な絵文字優位は示していない。

追加2組の候補長は不一致（5対7、7対8トークン）。全入力長は27〜45トークンだった。
長さ正規化は追加せず、トークン化を揃えたとも主張しない。共通候補文と課題固有文では
具体性も異なる。追加の手がかりなし条件は測定していない。元の手がかりなしスコアを
新候補へ流用することもできない。統合1,152セルは**24課題**への反復測定であり、
familyや手がかりの共有も独立性を制限する。独立した課題が72になったとは扱わず、
推測統計のp値や信頼区間も報告しない。

意味や因果の主張へ進むには、解釈・意味等価性の独立検証、候補文とトークン長の効果を
分離する応答対照、その後の未使用課題での検証が必要になる。
この結果だけを理由に、追加実験を自動的に開始することはしない。

## 空きVRAMでの試行と、過去データとの完全一致

取得ソース：`610fc77f3a371f8b983e43db179ba1718ef0cd61`。炉の独立checkoutで既存の
モデルと過去と同じBF16 CUDA runtimeを使った。download・量子化・学習・Aetherの
設定変更は行っていない。読み込み込みの所要時間は**710.54秒**。
2026-10-07 04:41:14〜04:53:05 UTC（13:41:14〜13:53:05 JST）に実行した。

重みをCPUに保持してdecoder blockを1つずつ転送する方式で、**過去384/384セルの
完全一致**を確認後、**追加768/768 forward**を完了した。合計1,152回の試行。
過去の各トークン対数確率と合計はすべて完全一致し、許容差は緩めていない。
基本runtime JSONは過去とバイト単位で同一。重み配置の変更は別記録にした。
過去セルの工学的再現であり、新しい科学的確認データではない。

- 自プロセスのGPUメモリ最大観測値：**1,666 MiB**（約1.63 GiB）。
- PyTorch割り当てpeak：**979.38 MiB**、予約peak：**990 MiB**。
- 空きVRAMの最小観測値：**6,868 MiB**。下限4,096 MiBを上回った。

- その後、AetherのGPU割り当ては観測されなくなり、実行の大半は非共存だった。
  **長時間共存や、Aetherの学習速度に影響がなかったことは未検証**。Aetherの
