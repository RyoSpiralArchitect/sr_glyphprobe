# Mistral semantic atlas token-structure sensitivity v0

[日本語](MISTRAL7B_SEMANTIC_ATLAS_TOKEN_STRUCTURE_V0.ja.md) · [Canonical batch-one protocol](MISTRAL7B_SEMANTIC_ATLAS_BATCH1_V1.md)

Status: **post-outcome sensitivity design**. The complete discovery headline
was known before this exact stratification was written, so no result here is
confirmatory or eligible to replace the untouched reserve test.

Of 842 discovery items, 760 glyphs have exactly five Mistral tokens and the
same first three token IDs, `[29473, 1011, 930]`. This dominant stratum removes
glyph-token-count variation and fixes the long shared prefix. The sensitivity
reruns every descriptive cross-view metric over all 72 fixed cells for:

- all 760 common-prefix five-token glyphs;
- name-token-count strata 1–5 with counts 105, 257, 213, 111, and 43;
- codepoint-token-count strata 6 and 7 with counts 180 and 573.

The 43-item name-token-count-five stratum gives equal glyph/name token counts.
No triple view has equal token counts in the discovery population, so this is
not presented as a fully token-isomorphic three-view control. Strata below 20
items are omitted by a tokenization-only size rule fixed before this
sensitivity is run.

All strata, layers, carriers, and distances are retained. There is no p-value,
threshold, multiplicity decision, or favorable-stratum selection. Persistence
of glyph/name retrieval relative to codepoint retrieval would narrow the simple
glyph-length explanation, but would still not remove token identity, establish
semantics causally, or close a paper gate.
