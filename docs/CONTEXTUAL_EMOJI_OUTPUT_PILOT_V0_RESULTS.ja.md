## 何を測ったか

著者が作成した6系列・24シナリオで、目的の異なる二つの文脈と、二つの絵文字を交差させ、
各入力に対する同じ二つの応答候補を採点した。両文脈で絵文字を除いた条件も採点した。
計144入力・**288候補文セル**を、既存のLlama 3.2 3B base BF16で欠測・失敗なく取得した。

候補文を与えて文全体の条件付き確率を測る実験であり、回答の自由生成ではない。
CLDRキーワードを正解に使わず、読み出し状態のリセットや内部活性への介入も行わない。
ラベルは著者が想定した解釈であり、独立した人間の判断で確立した正解ではない。
絵文字が同じ状態を表したままでも、文脈上の目的との相互作用は生じる。
この設計で絵文字自体の意味の変化を証明したとはいえない。

`s(c,e)`は、すべての入力で同じ候補Aと候補Bの対数確率差である。
`Delta_p`と`Delta_q`は、各文脈で絵文字AをBに替えたときの、その差の変化。
各シナリオの符号`eta`により、`H = eta * (Delta_q - Delta_p)`の正方向を
著者の仮説にそろえる。単位は自然対数のnats。p値、信頼区間、母集団への一般化は報告しない。

## 結果と、それぞれが意味する範囲

| 診断 | 観測 | 解釈の限界 |
| --- | ---: | --- |
| 目的×絵文字の交互作用が正、`H > 0` | **23/24シナリオ** | 絵文字交換の効果が想定方向に変化した。効果の符号や、選ばれる応答の反転を必要としない。 |
| 想定方向の効果反転、`eta * Delta_p < 0 < eta * Delta_q` | **12/24シナリオ** | 文脈によって絵文字交換の効果の符号が反転した。最も確率の高い候補の反転とは別である。 |
| 高確率の候補が著者の想定ラベルと一致 | **54/96交差入力** | 取得後に追加した診断。人間が検証した正解率や、自由生成の成績ではない。 |
| 4入力すべてで想定した候補が高確率 | **0/24シナリオ** | 四つの絶対的な応答選好をすべて満たしたシナリオはない。 |
| 6系列を等重みにしたHの平均 | **1.3122693 nats** | この有限の開発集合における記述値。意味上の重要性を較正した効果量ではない。 |

最初の二つは取得前に指定した診断である。絶対的な候補選好の診断は、交互作用と応答選好を
区別するため、結果を見た後に追加した探索的な指標である。同点は一致と数えない。
負の交互作用を示した`direction_02`（H = −0.2226228）も保持し、結果による除外はしていない。

完了状態の系列では、この区別が特に明確である。Hは4件とも正だが、想定方向の効果反転は

逆に、`thermal_01`ではH = 1.107030で想定方向の効果反転もあるが、四つの交差入力すべてで
候補Bの確率が高い。効果の反転があっても、四条件に応じた応答の選択が成立するとは限らない。

## 分かったことと、残る課題

実装した指標で、この開発集合における通常の候補文の相対確率が、文脈によって異なる
変化を示すことを観測できた。対照を加えて調べる理由になる。ただし、絵文字特有の意味、
安定した課題遂行、自然な利用場面、内部の因果経路はまだ確立していない。
繰り返し使う6系列・各シナリオ1候補対であり、24種類の独立した現象でも、
表現の違いに頑健なベンチマークでもない。

絶対的な候補選好には、重要な未解決点が表れている。正の交互作用があっても、特定の
候補を好み続ける場合がある。肯定・否定表現、長さ、語彙の選択、文脈に依存した
トークン化の寄与は残る。A/Bとetaの付け替えは記号上の整理にすぎず、これらへの対照では
なかった。絵文字なし条件も空のメッセージを残すため、独自の入力上の問題がある。

同じ文脈で絵文字A/Bのトークン位置配列を比較すると、**24/48対で不一致**だった。
この基線実験では除外していない。同じ位置のK/V交換を全件にそのまま適用することは
できず、今後は効果を見ずに適格条件を決め、除外数も残す必要がある。
残る位置一致だけで、意味や因果に関する比較可能性が保証されるわけでもない。

| 必要な作業 | 現状 |
| --- | --- |
| 曖昧・両方・どちらでもないを許す独立した人間の解釈確認 | 未実施。すべて著者想定ラベルのまま |
| 固定した追加の候補文表現 | 未実施。J = 1 |
| 通常の単語への置換対照 | 刺激データに案はあるが、モデル採点は未実施 |
| 非絵文字記号と、凡例をそろえた対照 | 設計・採点とも未完了 |
| 通常状態での双方向メッセージ交換 | 実装・実行とも未実施 |
| 新しい系列での確認と、第2モデル系列 | 未実施 |

次の限定的な開発実験では、固定した単語対照と複数の候補文表現を、弱い結果・負の結果も
含む**全6系列**で比較する。最小の一歩は、既存の単語対と同じ候補文による
24シナリオ×2文脈×2単語×2候補＝192セルの追加採点である。
候補文の言い換えは、別の後続実行として扱う。本版を保存し、各実行範囲は走らせる前に決める。
最も強かった系列だけを取り出して、未使用の仮説のように扱わない。その後に独立した
刺激の妥当性確認と較正した因果実装へ進む。確認には別途準備した新しい系列が必要になる。
