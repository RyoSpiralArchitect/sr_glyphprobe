# Mistral 7B semantic atlas reserve confirmation v0 evidence

[日本語](README.ja.md) · [Results](../../docs/MISTRAL7B_SEMANTIC_ATLAS_RESERVE_CONFIRMATION_V0_RESULTS.md) · [Frozen protocol](../../docs/MISTRAL7B_SEMANTIC_ATLAS_RESERVE_CONFIRMATION_V0.md)

This compact bundle binds the freeze, single-use 292-item reserve acquisition,
complete eight-cell analysis, fixed randomization decision, furnace execution
receipt, and result-return verification.

The run used 1,752 canonical batch-one forwards to capture 7,008 layer-31 FP32
vectors in ten complete shards. There were no partial shards, interventions, or
generations. The fixed primary rule passed: the minimum glyph/name minus
glyph/codepoint top-1 contrast was `0.171233` against a practical floor of
`0.02`; none of 19,999 common-permutation draws reached the observed statistic,
giving `p = 0.00005`.

Raw activations (~111 MB) and 292 item-level retrieval rows remain outside Git.
The bundle retains the run and session receipts, complete eight-cell metrics,
primary result, execution/return receipt, and exact hashes.

This evidence authorizes a confirmatory alignment claim in the fixed model,
layer, and transport grid. It does not authorize semantic, causal,
tokenizer-independent, model-general, or complete Phase I claims.
