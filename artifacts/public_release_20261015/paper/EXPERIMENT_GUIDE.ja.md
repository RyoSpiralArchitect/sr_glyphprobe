# 実験ガイド：キーワード検索から条件付き介入まで

[English](EXPERIMENT_GUIDE.md)

この研究は、テキストモデルが生の Unicode 絵文字からどのような語彙情報を
検索できるかを調べ、その情報が隠れ状態に関与する経路を限定して検証する。
描画された画像の知覚、人間にとっての意味、生成応答の振る舞いは測定していない。
以下では内容を表す名前で実験を説明する。プロトコルと結果に記録された実験 ID は
変更しない。

## 四つの問いと実験

「固定」は、ソース項目から閉形式で求めた基底を評価中には変更しないという意味であり、
手作業で恣意的に選んだ基底という意味ではない。「最適化」は介入を通じて基底を学習する

必ずしも疎ではなく、あるランク8の介入群が基準を満たさなくても、あらゆる因果説明が
否定されたことにはならない。

## 一つの例で入力と読み出しを追う

既存の設計例 U+1F923 には、次の四つのテキスト表現がある。

| 表現 | トークナイザーに渡す文字列 |
| --- | --- |
| 生の Unicode | `🤣` — Unicode スカラー U+1F923 そのもの |
| コードポイントの文字列表記 | `U+1F923` — スカラーではなく ASCII の表記 |
| CLDR 公式名 | `rolling on the floor laughing` |
| CLDR キーワード | `lmao` |

キーワードと公式名には、ASCII の英数字で区切った共通単語がない。ただし、それだけで
人間が同義語と認めたことにはならない。学習データで共起していた可能性や、トークナイザーの
特徴を共有する可能性は残る。これは設計の説明例であり、**この個別項目がいずれかの実験で
成功したという主張ではない**。

例えばパイプのキャリアでは、各表現に別々に ` |` を8個付ける。
`🤣 | | | | | | | |`、`U+1F923 | | | | | | | |` などが入力となる。
距離1の読み出しは最初の接尾辞トークン、距離8は8番目の接尾辞トークンの隠れ状態を取る。
モデルに `lmao` と出力させるわけではない。隠れ状態のベクトルをキーワードのギャラリーと
比較する。キーワード検索では、表現ごとに中心化し、各ベクトルを正規化した後、最近傍が
同じ項目かを調べる。後の注意経路実験では、正解キーワードとのコサイン類似度から、固定した
ソース用キーワード128個への類似度の最大値を引いたマージンを用いる。

問いは次の順に進む。

1. **読み出せるか。** 生の文字から対応するキーワードを検索できるかを、コードポイント
   表記を参照しつつ、固定した文脈群で調べる。
2. **除去・転送するとどうなるか。** 別のソース項目からランク8の基底を学ぶ。絵文字入力の
   計算からその座標を除く、または同じ項目の絵文字座標をコードポイント入力の計算へ
   転送する。同じランクのランダム部分空間での操作と比較する。除去と転送は異なる
   介入条件であり、一回の計算を二通りに読むわけではない。
3. **最適化し、参照効果を確かめるとどうなるか。** 介入を通じて部分空間を学習し、残差列の
   部位を追加して、全状態交換と比較する。T20はキーワードtop-1だけで判定し、
   コードポイントの自己検索率にも制約を置く。コードポイントの同一性を失ったことを、
   キーワードを獲得したことと取り違えないためである。
4. **条件付きの経路はあるか。** ブロック21直後の読み出し残差を、同じ項目のコードポイント
   表現の状態で置換する。後段のブロック22–27では、読み出しクエリに限って、選択した
   過去位置のキーと値を置き換える。絵文字位置のメッセージの除去・復元を、同数の接尾辞
   位置への介入と比較する。参照条件にも同じ読み出し状態の置換を残す。

最後の実験が問うのは、**指定した状態置換の後に**何が寄与するかである。それ以外を
変更していないモデルで、同じ経路が必要または十分だと示すものではない。

## トークン数を揃えるとは何か

各項目には、文字種と四つの表現のトークン数からなる組がある。
`(文字種, 生の文字, 公式名, キーワード, コードポイント表記)` である。
一致解析では、この組が完全に同じ項目が2個以上ある層だけを残し、キーワードの対応を
同じ層の中でのみ並べ替える。

これは、**一つの項目の四表現をすべて同じトークン数にすることではない**。
例えば `(絵文字, 2, 6, 2, 5)` という組を持つ絵文字同士は同じ層に入る。この数値は
説明用の仮例であり、U+1F923の実測値ではない。揃えるのは項目間のトークン数の組であり、
トークンの同一性、トークナイザーの構成、学習頻度、意味上の親しみやすさは統制していない。
無制約解析と一致解析では残るギャラリーも異なるため、効果の大きさをそのまま同一視できない。

ランダム化検定が問うのは、固定されたキーワード対応が、許されたキーワードの並べ替えを
上回るかである。コードポイント側の項は固定したままなので、キーワードとコードポイントの
等しさに対する対応のある有意差検定ではない。登録済みの判定では、これとは別に、観測された
キーワード検索率とコードポイント検索率の差にも下限を設けている。

## なぜ0.02か。判定はどの程度この値に依存するか

事前に定めたT19プロトコルは、top-1の差の指標に0.02、すなわち2パーセントポイントの
下限を定めている。この数値について、効用、人間にとっての意味、検出力に基づく独立した
校正は示されていない。T20は判定指標をキーワードtop-1だけに変更しつつ、この下限を
引き継いだ。事前に定めることは、結果を見て都合のよい閾値を選ぶことを防ぐ。しかし、
それ自体が閾値の科学的な根拠になるわけではない。

判定規則にも違いがある。T19-Lでは、無制約・一致の両方の点推定値に下限を適用し、
ブートストラップ区間は記述用とする。T19-C/T20-Cでは、両介入効果とそれぞれの95%下限が
ともに閾値を超え、登録済みの検定と対照も満たす必要がある。T21の単位は別の
コサイン・マージンで、五つの同時下限がゼロを上回ることを要求する。実用的な効果量の
主張はしておらず、この指標に0.02をそのまま適用してはならない。

以下は、**保存済みT19-L推定値を用いた記述的な算術比較**である。既存のランダム化検定の
結果は固定している。新たな確認解析でも、閾値を変更する提案でもない。

| 仮のtop-1下限 | 両点推定値の下限と既存のモデル検定を満たす構成 | 主要4構成 | 主要4構成中3構成以上という効果量条件 |
| --- | ---: | ---: | --- |
| 0.02 または 0.03 | 9/9 | 4/4 | 満たす |
| 0.04 または 0.05 | 8/9 | 4/4 | 満たす |
| 0.06 | 6/9 | 4/4 | 満たす |
| 0.07 | 5/9 | 3/4 | 満たす |
| 0.08 | 4/9 | 3/4 | 満たす |
| 0.09 | 2/9 | 1/4 | 満たさない |

9構成すべてという記述は下限0.036363636まで、主要4構成中3構成以上という条件は
0.082516340まで保たれる（数値は丸め）。この下限だけを変えても保存済みのランダム化検定は
変わらないため、記録された部分連言検定の p は0.0027のままである。

一方、介入の下限をゼロまで下げても、保存済みT19-C/T20-Cのどの部位も陽性にはならない。
すべての部位で、少なくとも一方の下限がゼロ以下であり、部位のIUT p値も0.05を上回る。
ただし、この事実で校正の問題が解消するわけではない。T20の全状態交換に別途設けた
参照効果の下限0.06は、より小さいT19の項目集合から選ばれたが、T20のベースラインの
キーワード検索率の差は0.03320しかない。結果を見た後で参照効果の下限を下げれば
解釈ラベルは変わり得るが、介入の成功を示すことにはならない。全状態交換は有用な
参照介入であって、部分空間への介入効果の普遍的な上限だと証明されてはいない。

## なぜブロック21、24、27か

観測実験の後段の窓は、T19の取得前にT18から引き継がれた。正規化深度は
0.75、0.875、1.0で、記録された変換規則は
`min(L - 1, floor(fraction * L))` である。28ブロックのLlamaでは、0始まりの
ブロック番号21、24、27、すなわち22番目、25番目、28番目のブロックになる。
これは番号の由来を説明するが、普遍的な「意味の段階」を示すわけではない。

T19はブロック24の注意・MLP出力を主要部位とし、21/27を副次部位に固定している。
参照プロトコルにはこの事前指定が記録されているが、24だけが主要部位として適切だと示す
独立した実証的な校正はない。T20は残差21/24を主要部位にする。残差27は読み出しの
直前にあるため、その転送効果は評価指標の整合性を確かめる性質が強く、副次部位とする。
T21では、すでに評価済みの項目を使うパイロットに事前指定の選択規則を適用して、21/24から
アンカー21を選び、その後に別の195項目で確認している。

保存済みの深度別要約からは、新たなモデル計算なしに記述的な確認ができる。後段の
三つの深度をそれぞれ単独で集計しても、全9構成で両解析の点推定値が0.02を上回る。
構成・解析成分を通じた最小値は、深度0.75で0.02045、0.875で0.05000、1.0で0.03182。
後段の深度を一つずつ除いた平均も、すべて0.02を上回る。ただし、これらの確認によって
主要解析のp値を個別の深度や別の深度窓へ引き継げるわけではない。保存済みの全深度を見ると、
モデルごとのピークは初期ブロックを含めて異なる。共通の後段開始点は示されていない。
介入を実施していない深度の効果についても、ここから結論は出せない。
