## 移植可能な読み出し記録

`evidence/readout_qualification_v1/` には、公開対象の項目を明示して抽出した
`specification.public.json`、`forwards.public.jsonl`、`analysis.public.json`、
`independent_validation.public.json`、`run_summary.public.json`、
`runtime_dependencies.public.json`、`projection_binding.json` を含みます。
予定した全条件、プロンプト、継続文、トークンID、状態、スコア、参照ラベル、
不合格、同点を残します。端末内パス・プロセス情報・識別情報を含み得る例外文は省き、
実行全体またはソースの対応づけに失敗したかは真偽値として明示します。

作成処理は実験前に保持した仕様ハッシュ、生の実行ファイルのハッシュ、ソースの
対応を確認し、公開用抽出の前後で解析が等しいことを要求します。数値条件を満たす
完了runでは、別の算術実装でも両方を確認します。生の記録は編集しません。
パッケージ作成中のモデル計算、トークン化、ダウンロード、アップロードはありません。

## ローカルでの作成

Pythonと `pypdf` のあるソースリポジトリで実行します。未作成の出力先を選び、
既存資料集は上書きしません。任意の文書検証記録は新しい独立版PDFそのものを
ハッシュで結び付ける必要があります。対応する検証記録がなければ省き、
以前の候補版のPDF記録を別のPDFへ流用しないでください。

```bash
python3 -B paper/scripts/build_public_release_20261015.py build \
  --pdf output/pdf/glyphprobe_preprint_20261015.pdf \
  --specification validation/readout_qualification_v1/specification.json \
  --expected-specification-sha256 5273b1f86db4ee956659a94ca7f047856e86b5f857fdf66efc5d96e5f85c487f \
  --run-directory validation/readout_qualification_v1/run4640 \
  --author-license-confirmed \
  --output output/artifacts/glyphprobe_public_release_20261015.zip
```

任意の `--document-validation FILE` は確認済みの記録を
`evidence/document_validation.public.json` に含めます。任意の `--metadata FILE`
は作業者が確認した公開メタデータを含めます。DOIを含む場合は、外部で既に予約された
識別子を `doi_status_at_preparation: "reserved_not_registered"`
（または簡略形 `doi_state: "reserved"`）とともに指定します。この指定自体はDOIの予約・確認を
行わず、公開済みとも扱いません。作成結果はローカル整合性の記録で、公開の証明ではありません。

`ARTIFACT_MANIFEST.json` は厳密なファイル一覧、サイズ、ハッシュ、ライセンス区分、
機械的なプライバシー検査の種類、未公開の準備状態を記録します。
`SHA256SUMS` はそのmanifestも結び付けます。明示的な許可リストとTeX依存関係だけを
使い、非公開リポジトリ全体は複製しません。PDFの本文・メタデータ・注釈・バイト列には
保守的な機械検査を行いますが、著者によるプライバシーと権利の確認は別途必要です。
これは実名の公開プレプリントで、匿名査読用ファイルではありません。

ZIP内の日時は再現可能な梱包のためだけに固定し、実験日時・公開日時とは扱いません。
モデルとトークナイザーのファイル、非公開の個別記録、環境、キャッシュ、認証情報を除外します。

## 展開後の検証

展開先に追加ファイルを作る前に、そのルートから実行します。

```bash
python3 -B paper/scripts/build_public_release_20261015.py verify .
```

Python標準ライブラリだけで厳密な一覧とハッシュ、現行論文がワークショップに
依存しないこと、2つの算術実装による新しい適格性検査の保存スコア再計算を確認します。
以前の候補版作成スクリプトは変更していない共通処理の依存としてのみ含め、
その古いライセンス・公開状態の既定値を今回の資料へ適用しません。

過去資料集には別の再計算手順があります。検証の成功はパッケージ整合性と保存スコアの
算術を示し、意味的妥当性、独立した人手確認、未観測の因果機構を立証しません。
