Does an emoji prefix separate Llama-3.2-3B's residual stream more than a random direction?

Held-out emoji fingerprint separation vs a matched random-direction control, per cell (strength × seed), for the two probed depths. Higher = more separable. The emoji direction beats the random control at layer 11 — but not at layer 5, where the noisy control often wins.

emoji-conditioned direction random-direction control gap = advantage  ▶ + emoji ahead · ◀ − control ahead

What this is. A deliberately out-of-contract exploratory run of the GlyphProbe internal harness on the real bf16 Llama-3.2-3B (transformers · MPS · FP32), 10-glyph colored_shapes panel, 24 targets, 16 wrappers, 3 seeds, 3 strengths. It is not the sealed v2 experiment and reuses different library versions.

How to read it. "Separation" is the leave-one-target-group-out prototype separability of the stored 96-d CountSketch output fingerprints; the random control repeats the pipeline with random directions of matched RMS. Every cell's within-target label-permutation screening p = 0.005.

What it does not show. This is a pre-causal activation screen — it does not establish emoji meaning, semantic families, tokenizer-independence, or any causal/mechanistic claim. The random control's separation is strongly seed-dependent (seed 211 runs high), and the source→target wrappers are not token-length matched, so tokenization remains a live confound.
