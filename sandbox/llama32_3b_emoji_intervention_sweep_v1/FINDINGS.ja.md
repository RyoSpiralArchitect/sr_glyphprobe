## 1. 問いと測度

絵文字を**一個ずつ**取り上げ、それがどれだけモデルを動かすか、そしてその答えが
*絵文字*の性質なのか単なる*トークン数*なのかを切り分ける。

意図的に別の問いに答える2つの量を測る。

**A — プロンプトレベル効果。** `KL( p(next | W) ‖ p(next | "<g>\n" + W) )` を
ラッパー文脈 `W` で平均。「文の前にこのグリフを置いたら次トークン分布はどれだけ動くか」。
動的レンジは大きいが、トークン数とトークンの希少性に交絡する。

**B — 強度統制された押し込み。** グリフの残差方向を抽出し、**全グリフ**を同一RMSに
正規化して保留プロンプトへ注入する:

```
方向    d_g(L) = mean_i [ resid_post(L, "<g>\n<W_i>") − resid_post(L, "<W_i>") ]
注入    v      = d_g(L) / rms(d_g(L)) · α · rms(a_target(L))     (activation_add)
スコア  KL(baseline ‖ intervened)  — RMS整合ランダム方向ヌルとの比で報告
```

B が「このグリフがどれだけ介入するか」の誠実な形である。注入前に全方向が
`α · rms(ターゲット活性)` に再スケールされるため、生の方向が大きいグリフが無条件に
有利になることはない。全指標はプロジェクト自身の `glyphprobe.analysis.metrics`、
すなわち封印済み研究と同一のコード経路で計算している。

**動作点。** α = 0.5。用量プローブから選定した — 線形域では KL は α² でスケールするので
グリフ/ヌル*比*は α 不変であり、α = 2.0 ではプローブ6グリフ中6で argmax が反転して
計算が壊れる。α = 0.5 では事実系ターゲット300セルで反転**0**件。
`mid` は層10–19における比の最大値と定義する。

**測定ゲート（全通過）。** ゼロフックは厳密な no-op（全セルでKLが恒等的に0.0）、
用量単調性はグリフ×層セルの100%、RMS整合は1,350注入で 2.2×10⁻¹⁶ まで一致、
モデルは意図した摂動を厳密に受け取る（`actual/intended RMS` = 1.000000、
`cos(actual, intended)` = 1.000000）。

## 2. 生き残ったもの

### 2.1 トークン数は介入量を説明しない

| 関係 | Spearman ρ |
|---|---|
| プレフィックストークン数 vs プロンプトレベル効果（50グリフ） | **+0.06** |
| プレフィックストークン数 vs 強度統制された押し込み（50グリフ） | **−0.08** |

パネルは2階層で構成した — **正確に4プレフィックストークン**の38グリフと、
**2〜16**トークンにまたがるラダー。2トークンの `★` と16トークンの 👨‍👩‍👧‍👦 は
統制階層と同じ帯に収まる。統制階層内でも、トークン数を完全固定したまま
プロンプトレベル効果は **3.9倍** の幅を持つ（🐶 0.586 → ⬛ 0.150）。

これは封印済み研究が抱える `wrapper_tokenization_control` HOLD より強い統制であり、
本作業で最も頑健な結果である。50グリフに基づき、ヌルに一切依存しない。

### 2.2 方向の類似性と因果的効力は独立

**26の合成ケース**において、2グリフ列の順序を反転させると、名前付き成分への
固定枠余弦は最大 **0.09** しか動かないのに、効力は最大 **0.94** 動く —
成分単体が 2.73〜5.66 に散らばる尺度の上で。

| ラン | ケース数 | 最大\|余弦シフト\| | 最大\|効力シフト\| |
|---|---|---|---|
| catchase v2 | 14 | 0.074 | 0.94 |
| meanrule v1 | 12 | 0.090 | 0.69 |

**2つのグリフ列は、残差方向がほぼ同一でありながら因果的押し込みが大きく異なりうる。**
既知の方向への余弦類似度は、その方向の効果についての証拠にならない。
最も多くのケースに支えられた発見であり、最も強く擁護できるものである。

### 2.3 ZWJ接合子は合成の効力低下の原因ではない

🐈‍⬛ は「🐈のトークン + ZWJトークン + ⬛のトークン」に**厳密に**分解される
（実行時に検証し、崩れていればランナーは exit 2 する）。したがって接合子の除去と
順序の反転を独立に操作できる。

| | 接合あり | 接合なし | 差 |
|---|---|---|---|
| 👩 → 💻 | 3.3933 | 3.3870 | 0.006 |
| 🐈 → ⬛ | 3.090 | 3.305 | 0.215 |
| ⬛ → 🐈 | 3.516 | 3.615 | 0.099 |

接合子を外しても 🐈⬛ は 3.31 で、🐈 の 3.96 には遠い。接合子は*無効果ではない* —
0.006〜0.215 は他所で信号として扱った順序効果と同程度である — が、原因ではありえない。

### 2.4 合成は成分の平均に従う（事前登録済み）

失敗した仮説の再解析中に**事後的に**見つけたため、6件の予測と二部構成の判定基準を
[`PREREGISTRATION_mean_rule.md`](PREREGISTRATION_mean_rule.md) に書き、
**検定スクリプトが存在する前に**コミットした（`65e0307`: 1ファイルのみ、
スクリプトもデータもなし）。ランナーは起動時に予測・閾値・規則係数を再導出し、
食い違えば中断する。

```
composite_mid ≈ 0.70 · mean(component_mid) + 1.16
```

| 基準 | 要求 | 観測 | |
|---|---|---|---|
| Spearman(予測, 観測) | ≥ 0.70 | **+0.886** | PASS |
| 平均絶対誤差 | ≤ 0.72 | **0.308** | PASS |

成分11体すべてが過去測定値を再現した（分解能の注記: 過去値は2桁保存なので、
再現成功時の誤差は**構造上** 0.005 未満に収まる）。これは追跡の発端となった謎にも
答える — **🐈‍⬛ が弱いのは 🐈(3.96) と ⬛(3.00) の平均が 3.48 だから**であり、
接合子でも順序でもない。

**n = 30 で再検定した。** リポジトリ自身の `e2_core35` パネル（私が選んでいない
プール、全グリフが正確に4トークン）から種固定サンプラーで30ペアを引き、係数は
凍結のまま（[レポート](results/meanrule30_report.md)、
[事前登録](PREREGISTRATION_mean_rule_n30.md)）:

| | n = 6 | n = 30 |
|---|---|---|
| Spearman | +0.886 | **+0.784**（PASS） |
| MAE | 0.308 | 0.409（PASS） |
| ブートストラップ95%CI | 算出不能 | **[+0.550, +0.907]** |
| 並べ替え検定 p | — | **0.0001** |

この区間こそ §5.1 が「n≈6 では出せない」と述べた量である。0を明確に除外する
—— **順序関係は実在する** —— が、下限は 0.70 の合格閾値を*下回り*、再当てはめは
凍結値 `0.70 / 1.16` に対し `0.62 × mean + 1.86`、30ペア中23で過小予測となる。
**順序として引用すべきで、大きさの予測子として引用してはならない。**

### 2.5 注入された方向は認識可能なトークンを押し上げる

質的だが最も直観的に読める結果。グリフの方向を `The capital of France is` に注入すると:

| グリフ | 押し上げ上位トークン |
|---|---|
| 🍕 | `' yummy'` `' delicious'` `' pizza'` |
| 🚗 | `' Automobile'` `' Vehicles'` `' cars'` |
| 🐶 🐱 🐻 🐢 | `' Animals'` `' Animal'` `' animals'` |
| 🇯🇵 | `' japan'` `' Japan'` `' Japanese'` |
| 👩‍💻 | `' Software'` `' Programming'` |
| 🏳️‍🌈 | `' Diversity'` `' Minority'` |
| 👨‍👩‍👧‍👦 | `' Family'` `' Kids'` |

第二のパターン: 多くのグリフ（🔥 🌊 ⚡ 🚀 🚂 🤯）では押し上げ上位が
**UTF-8部分バイト断片**になる。方向が部分的に「この概念を出せ」ではなく
「絵文字を出せ」を運んでいる。

方向が運ぶのは**個体ではなくカテゴリ**である。手書きのプローブ語
（モデル自身の出力から採取していない）で、自分のプローブ群が最大になるのは
**4/13** のみだが、自分の*カテゴリブロック*が最大になるのは **10/13**。
🍣 は *sushi* 語（+1.86）より *burger* 語（+2.95）を強く押す。

**これはスクリーンが生成したものの記述であって、意味論的主張ではない。**
ランダム方向ヌルは*大きさ*の対照であって意味の対照ではない。
これを上回ることは方向が構造化されていることを示すが、その構造が「意味」であることは示さない。

## 3. 生き残らなかったもの

7件の主張を述べ、そして撤回した。3件は敵対的レビューが、4件は私自身の追加測定が発見した。

| 主張 | どう死んだか |
|---|---|
| 「全グリフがランダムヌルを上回る」 | ヌルの*中央値*についてなら真。ノンパラメトリックには**どの層でも3ターゲット全てをクリアするグリフは存在しない** |
| 「層プロファイルはパネルを例外なく二分する」 | 中間例を含まない13体パネルの性質。19体では中層比は**連続体**（2.71→5.66、最大ギャップ0.73） |
| 「方向は最後の成分に従う」 | cos-to-*first* と cos-to-*last* を比較していた産物。ラベルは順序とともに入れ替わるので、幾何が動かなくても列が反転する |
| 「順序効果は成分差でスケールする」 | **2家族**から読み取った。n=7 で Spearman **+0.04**、n=6 で **−0.94** |
| 「順序効果の符号は一貫（6/7）」 | 確証集合は**2/6**で逆。プールして 8/13、偶然期待値 6.5。**n=30 で更新 — 下記参照** |
| 「接合の有無で同値（3.39対3.39）」 | 2桁表示の産物。実際は 3.3933 と 3.3870 |
| 「非食べ物対照は反転し、食べ物と区別できない」 | 条件ごとに strong/weak を再判定していたため3セルが鏡像化。基準固定では**対照は両方とも安定** |

**撤回のうち1件は、それ自体が慎重すぎた。** n = 30 では順序効果は消えておらず、
当初の主張とは*逆向き*に出る — **30ペア中8ペアが陽性**（偶然は15、二項両側
**p = 0.016**）、中央値 **−0.32**。**強い成分を最後に置くと*低く*なる。**
6/7 の主張は撤回に値し、8/13 というプール読みも当時の証拠に対しては正しかった。
5倍の単位数では、効果は符号を反転させて再出現する。これは 6/7 がかつて持っていた
のと同じ証拠水準の単一標本の発見であり、それ以上になるには自身の再現が必要である。

遅れて発見し、隠さず開示した交絡: **UTF-8バイト階級**がプロンプトレベル順位と相関する
（Spearman **−0.55**、トークン統制階層*内*でも **−0.48** なのでトークン数ではない）。
why-flatパネルの3バイト系 U+26xx/U+2Bxx グリフは全て下位半分に入る。
3バイトであることは弱い効果の十分条件に見えるが必要条件ではない。
最も可能性が高い読みはバイト階級が抽象性の代理変数だということで、
近義語ペア（⛵/🚢 1.35倍、☕/🍵 1.60倍、✈️/🚁 1.16倍、⬛/🟥 0.99倍）は
それが全てではないと示唆するが、緩い近義語4組は薄い証拠である。

## 4. 考察

**順序効果はペア単位では実在し、規則としては空である。** 🍕⬛ は4つの独立条件
（互いに素なラッパー集合2 × ターゲット集合2）で負の順序効果を保ち、🍔⬛ も一致する。
しかし 🍣⬛ は*逆向き*に安定、🍜⬛ と 🍺⬛ は反転、非食べ物対照 🐶⬛・🌈⬛ は*両方とも*安定。
つまり個別のペアは再現性のある選好を持ちうるが、それは成分差にも、意味カテゴリにも、
同一カテゴリの他メンバーにも従わない。保存されるのは符号だけで、
🍕⬛ は条件により −1.09〜−0.03 と動く。**安定なものが説明可能なものとは限らない。**

**検出可能性はグリフではなくターゲットに属する。**
`Spearman(注入プロンプトのベースラインエントロピー, ヌルをクリアしたグリフ数) = +0.70`。
尖った事実系プロンプト（` Paris`・` Jupiter`）は*ランダム*方向でも大きく動くため効果が
埋もれる — そこではヌルが広く（sd 0.043）、開放型プロンプトでは狭い（sd 0.008）。
1つのプロンプトで結果を報告することは、グリフについてと同じくらいプロンプトについて
語ってしまう。最初のスイープが陥ったのがまさにこの罠だった。

**有意性と効果量は乖離する。** 弱い対照も12ターゲット中6〜7でヌルをクリアし、
🍕 や 🍺 と同数である。二値検定は飽和する。順序は比の大きさにしか宿らない。
「N セルで p < 0.05」と報告することは、真であり、かつ無情報だっただろう。

**深さ構造。** 絵文字方向が最も強く押すのは **L14–L16** で、意味的に豊かなグリフでは
最終層までにほぼ同等まで落ちる。**L0 では全グリフが比 0.05** — 埋め込み層では実在の
絵文字方向は整合ランダム方向より約20倍*乱さない*。おそらくモデルが穏やかに扱う
トークン埋め込み多様体の上にあるためである。方向の文脈間一貫性は逆走する
（L0 で 0.93 → L27 で 0.43）: **方向が最も再現的な場所で、効果は最も小さい。**
最終層での高い比は方向が*トークンらしい*ことしか意味せず、L14–16 のコブは
残りの計算に噛んでいることを意味する。特筆すべきは、姉妹の契約外スクリーンが
フィンガープリント*分離*に **L11** を最良としたのに対し、L11 は因果的押し込みでは
*最弱*の深さだという点である — 分離可能性と効力は層を同じ順序に並べない。

**合成は圧縮する。** 当てはめた規則の傾きは 0.70 < 1 で、合成は中央へ引かれる。
残差は示唆的だが未検証である: 双子ペア 🐈🐱（同一概念の2つの名前）は線の
**+0.54 上**、🍕🚗（強く無関係な2概念）は **−0.83 下**。
「似たものは加算的、異質で両方強いものは干渉的」は、このデータが*生成した*仮説である。

## 5. 方法論上の教訓

最も高くつき、最も遠くまで一般化するもの。

1. **n ≈ 6 の Spearman は測定ではない。** 同一プロトコル上の同一統計量が、
   2標本で +0.04 と −0.94 を示した。この設定で10単位未満の順位相関は、
   仮説生成器としてのみ扱うべきである — 事前登録検定を*通った*平均則を含めて。
   **n = 30 で建設的に確認された**: 平均則はブートストラップCI [+0.55, +0.91] で
   生き残り、6/7 → 2/6 と読めた順序効果は 8/30 で符号を反転して決着した。
   ここでの小標本は単にノイズを加えたのではなく、**向きを間違えていた**。
2. **綺麗な二分は大抵パネルの性質である。** 「例外なし」は13グリフで成立し、
   19グリフで崩壊した。二分法を主張する前に、群の中間に来る事例を足すこと。
3. **機構より先に指標を確かめる。** 2つの結論が指標のバグで反転した —
   条件とともに入れ替わるラベルと、ループ内で再判定される strong/weak 割り当て。
   データではない。どちらも尤もらしく、発表できそうなパターンを生んだ。
4. **説明する前に現象の実在を確かめる。** 🍕⬛ の安定性検定は、その異常を消すために
   設計した。生き残ったからこそ追跡が正当化された。それ以前の3つの「説明」は、
   後に蒸発したパターンに当てはめられていた。
5. **仮説が事後なら事前登録し、閾値も固定すること。** ガードの初版は予測*値*を
   検証していたが合否*閾値*を検証していなかった — 結果を見てから編集できる側が、
   まさに結論を決める側だった。
6. **共有分母の再シードは独立標本ではない。** ヌルは両順序が共有する分母に入るので、
   再シードは順序効果を定数倍するだけで符号を動かさない。実際に標本変動を担うもの
   — 方向推定と読み出し — を変えること。

## 6. 限界

- 1モデル（Llama-3.2-3B bf16）、1サイト（`resid_post`）、1位置（`last_nonpad`）、
  主強度1点（α = 0.5）。
- 全パネルを私が組んだ。確証集合は探索集合とプロトコルも著者も共有する。
  これは1つのsandbox内での再現であって、独立な再現ではない。
- 合成13家族・順序9ペア、すべて2成分。「4条件で安定」は弱い基準である —
  符号が真に五分五分なら8ペアに1つは偶然そう見え、9ペアを検定している。
- ランダム方向ヌルは大きさの対照であって意味の対照ではない。
- 非正準な来歴: 凍結外のライブラリ版と `orjson` 代替のため、レシートハッシュは
  正準実行と比較できない。
- 数値の注記: macOS/Accelerate 上の numpy は大きな float64 内積で
  `divide by zero / overflow / invalid value encountered in matmul` を偽陽性で出す。
  偽陽性であることを検証済み — 活性とロジットは全て有限で、`a @ b` は純Python総和と
  ビット一致する。
