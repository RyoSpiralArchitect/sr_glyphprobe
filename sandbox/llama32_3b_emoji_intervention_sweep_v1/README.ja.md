## 問い

絵文字を**一個ずつ**取り上げ、それが実際どれだけモデルを動かすかを測る。
そのうえで、その答えが**絵文字そのもの**の性質なのか、単なる**トークン数**なのかを切り分ける。

グリフごとに2つの量を測る。両者は意図的に別の問いに答えている。

| | 問い | 測り方 |
|---|---|---|
| **A. プロンプトレベル効果** | 「文の前にこの絵文字を置いたら、次トークン分布はどれだけ動くか」 | `KL( p(next \| W) ‖ p(next \| "<g>\n"+W) )` を4ラッパーで平均 |
| **B. 強度統制された押し込み** | 「…その動きは方向が*特別*だからか、単に*大きい*からか」 | グリフの残差方向を抽出し、全グリフを**同一RMS**に正規化して保留ターゲットへ注入し、KLを測る |

**B** が「介入量」の誠実な版である。注入前にすべての方向が
`alpha × rms(ターゲット活性)` に再スケールされるため、生の方向が大きいグリフが
無条件に有利になることはない。報告するスコアは**RMS整合されたランダム方向ヌル**との比で、
1.0 を超えれば「まったく同じ大きさのランダム方向より強く押している」ことを意味する。

## 方法

```
方向    d_g(L) = mean_i [ resid_post(L, "<g>\n<W_i>") − resid_post(L, "<W_i>") ]
        4つの抽出ラッパーにわたる平均、位置は last_nonpad
注入    v = d_g(L) / rms(d_g(L)) · alpha · rms(a_target(L))     (activation_add)
スコア  KL(baseline ‖ intervened)（次トークン分布上）
```

- **抽出ラッパー**（4件）: `Today I saw a` · `My favorite thing is` · `Here we have` · `This reminds me of`
- **注入ターゲット**（3件、ラッパーと素）: `The capital of France is`（top-1 ` Paris`）· `The largest planet in our solar system is`（` Jupiter`）· `I am thinking about`（` the`）
- **層** `[5, 11, 16]` · **強度** `alpha ∈ {0.1, 0.5, 1.0}`（主軸 `0.5`）· （層×ターゲット×強度）ごとに**ランダム方向対照 24 本**
- **パネル**: 50 グリフを2階層に — `matched`（38グリフ、**全て正確に4プレフィックストークン**。実行時に*全ての*抽出ラッパーに対して再計算し、不一致があれば記録を書かずに中断する）と `ladder`（12グリフ、**2〜16**トークンにまたがる）
- 2,157 レコード、M4 上で 359 秒（MPS / FP32）

すべての指標はプロジェクト自身の `glyphprobe.analysis.metrics`
（`distribution_metrics` / `activation_delta_metrics`）で計算しており、
封印済みの研究と同一のコード経路を通っている。

### 測定ゲート（全通過）

| ゲート | 結果 |
|---|---|
| ゼロフックが厳密な no-op | 9つの（層×ターゲット）セル全てで KL **厳密に 0.0** |
| KL の用量単調性 | グリフ×層セルの **100%** が `alpha` に対し狭義単調増加 |
| RMS 強度整合 | 全1,350注入で max\|実測 − 要求\| = **2.2e-16** |
| モデルが意図した摂動を厳密に受け取ったか | `actual/intended RMS` = **1.000000**（min = max）、`cos(actual, intended)` = **1.000000** |
| パネルのトークン数 | 50件すべて事前調査値と一致 |
| 主動作強度が計算を壊さずに摂動しているか | `alpha = 0.5` の事実系ターゲット300セルで **top-1 反転 0 件**（` Paris` と ` Jupiter` は常に保持） |

`alpha = 0.5` で生じる反転（44件）はすべて層16・開放型ターゲット上のもので、
そのベースライン top-2 マージンはわずか 0.49 ロジット — ` the` と ` a` / ` making`
の実質同着であり、計算の破壊ではない。`alpha = 1.0` では事実系ターゲットも反転し始めるため、
`0.5` を主動作点としている。

## 結果

### 1. トークン数はランキングを**説明しない**

これが最重要の結果。本プロジェクトの他所で `HOLD` となっているトークン化交絡は、
ここでの数値を駆動していない:

| 相関 | Spearman ρ |
|---|---|
| プレフィックストークン数 vs プロンプトレベル効果（全50） | **+0.06** |
| プレフィックストークン数 vs 強度統制された押し込み（全50） | **−0.08** |

2トークンの `★` と16トークンの 👨‍👩‍👧‍👦 は、4トークン階層と同じ帯の中に収まる。
ここで測られているものが何であれ、「トークンが多いこと」ではない。

### 4. 層構造と、§3のどれだけが実際にヌルを超えているか

セルが *0-exceed* とは、24本のランダム方向の**どれ一つ**としてそのグリフのKLに
達しなかったことを指す。ここで得られる唯一の仮定不要な言明である。

| 層 | 比（中央値） | 一貫性 | 0-exceed セル | 3ターゲット全てで clean なグリフ | ターゲット別 0-exceed |
|---|---|---|---|---|---|
| 5 | 2.22 | 0.161 | 0/150 | **0/50** | paris 0, planet 0, open 0 |
| 11 | **1.82** | 0.233 | 50/150 | **0/50** | paris 0, planet 0, open **50** |
| **16** | **3.76** | 0.278 | 77/150 | **0/50** | paris 0, planet 27, open **50** |

**どの層でも、3ターゲット全てでヌルを超えるグリフは存在しない。**
強度統制された効果が明確なのは開放型ターゲット（`I am thinking about`。ヌルが最も
狭い — sd 0.008、対して `paris` は 0.043）のみで、層16の `planet` で部分的、
`paris` では皆無である。したがって §3 は主に1ターゲットに担われた実在の*順序*であり、
38件の個別に有意な発見ではない。プロンプトレベルの結果（§1・§2）はヌルに一切
依存しないため影響を受けない。

絵文字方向が最も強く押すのは層16で、**層11が最弱**。
特記すべき点として、[姉妹の契約外スクリーン](../llama32_3b_bf16_ooc_screen_v1/README.ja.md)では
フィンガープリント*分離*にとって層11が*最良*の深さだった。
問いが違えば答えも違う — 分離可能性と因果的押し込みは層を同じ順序に並べない。
方向の一貫性（4ラッパー差分の平均ペアワイズ余弦）は深さとともに単調に増加する。
深い層ほど絵文字方向は文脈をまたいで可搬になる。ただし依然 0.28 程度であり、
個々の文脈における差分の大部分は「文脈」であって「グリフ」ではない。

## 深掘り診断（追試ラン）

上記スイープには弱点が2つある — 注入ターゲットが3つしかなく、ヌルも24本しかない。
13グリフ（最強組・プロンプト首位組・弱い対照3つ・🐈‍⬛）に絞った追試で、これを
**12ターゲット**・**各256本のランダム方向**に増やし、**全層**を走査し、特異性検定を
追加した。全数値は [`results/deep_report.md`](results/deep_report.md)、
チャートは [`chart/deep_chart.html`](chart/deep_chart.html)。

**1. 一般化する。§4の「1ターゲットのみ」は見かけだった。** 12ターゲット中6つで
13グリフ全てがヌルをクリアし、ノンパラメトリックの下限 p = 1/257 = 0.0039 に到達。
検出可能性は*グリフ*ではなく*ターゲット*の性質である:
`Spearman(ベースラインのエントロピー, ヌルをクリアしたグリフ数)` = **+0.70**。
尖った事実系プロンプトはランダム方向でも大きく動くので効果が埋もれる。
スイープの順位は再現した（12ターゲット版との Spearman **+0.75**）。

**2. ただし有意性と効果量は乖離する。** 弱い対照（⬛ 🥺 ⛵）も12ターゲット中6〜7で
ヌルをクリアする — 🍕 や 🍺 とまったく同じ数。二値判定は飽和する。
強い組の比の中央値 4.36 対 弱い対照 3.09。順位は「有意かどうか」ではなく
「比の大きさ」にしか宿らない。

**3. 層プロファイルはこのパネルを二分する。**

> ⚠️ **後続で覆された — [平坦グリフの追試](#なぜ一部のグリフは平坦なのか追試)を参照。**
> 当初この節は「例外なく二分される」と書いていた。それは誤りで、*この13体パネル*の
> 性質だった（中間例がたまたま含まれていなかった）。19体に広げると中層比は
> **連続体**になり（2.71 → 5.66、最大ギャップはわずか0.73）、
> 二値の mid-peak/last-peak ラベルは中層の関与ではなく**最終層の値**に支配されて
> いることが判明した（☕ と 🚢 を誤分類する）。

| 形 | グリフ | 中層最大（L10-19） | 最終層 L27 |
|---|---|---|---|
| **中層ピーク** | 🍺 🍕 🍣 🍔 🌍 🚗 🍜 🐶 🐱 | **3.7 – 5.7**（ピーク L14-16） | 1.3 – 2.1 |
| 最終層ピーク | ⬛ 🥺 ⛵ 🐈‍⬛ | 2.7 – 3.1 | **3.8 – 6.4** |

L27 の `resid_post` はほぼ直接 unembedding に入るので、そこでのスパイクは
「その方向がトークンらしい」ことを意味し、L14-16 のコブは「残りの計算に噛んでいる」
ことを意味する。⬛ のピーク比 6.43 は本ラン全体の最大値だが、完全に前者の型である。
**L0 では全グリフが比 0.05** — 埋め込み層では実在の絵文字方向は整合ランダム方向より
約20倍*乱さない*。一方で方向の一貫性は逆走する（L0 で 0.93、L27 で 0.43）。
方向が最も再現的な場所で、効果は最も小さい。

**4. 方向が運ぶのは個体ではなくカテゴリ。** 手書きのプローブ語（モデル自身の出力から
採らないので対角が選択バイアスを受けない）で、自分のプローブ群が最大になるのは
**4/13** のみだが、自分の*カテゴリブロック*が最大になるのは **10/13**。
🍣 は *sushi* 語（+1.86）より *burger* 語（+2.95）を強く押す。失敗例が示唆的で、
⛵ は `vehicle` で **−0.48**（🚗 は **+1.27**）— 強いグリフと同カテゴリでも何も得られない。

**5. この追試が生んだ留保。** 符号反転の反対称性は約0.63にとどまり、α = 0.5 では
すでに線形域の外にある。抽出ラッパーを3倍（4→12）にしても一貫性は約0.4で飽和し、
効果の中央値はむしろ*下がる* — 4ラッパーで十分だった。またブロック分けに1つ失敗があり、
🌍 を雑多な `other` ブロックに入れたため、教科書的な中層ピーク形なのにブロック検定で
落ちている。これは分類の作為であって発見ではない。

## なぜ一部のグリフは平坦なのか（追試）

深掘りランで平坦だった4つ（⬛ 🥺 ⛵ 🐈‍⬛）こそ面白い — 機構は陰性例で見える。
**UTF-8バイト階級だけが違う近義語ペア**（⛵/🚢、☕/🍵、⬛/🟥、✈️/🚁）、
**ZWJ分解セット**（🐈‍⬛ / 🐈 / 🐱 / ⬛）、**感情セット**（🥺 / 😢 / 😭 / 🤔）で
組んだ19体パネルで3仮説を検定した。全数値は
[`results/whyflat_report.md`](results/whyflat_report.md)。

**3つとも棄却または限定的支持 — さらに上記の主張を1つ覆した。**

| | 仮説 | 判定 |
|---|---|---|
| H3 | 概念が張り付いていない | **棄却** — 19体すべて正解概念が top-1 か top-2。⬛ → `' black square with a white border'`、🐈‍⬛ → `' black cat with a white face'` |
| H2 | 🐈‍⬛ の方向が ⬛ 成分に支配される | **棄却** — L27 で `cos(🐈‍⬛, 🐈) = 0.94` 対 `cos(🐈‍⬛, ⬛) = 0.77`。全層で猫寄り、差は深いほど*拡大* |
| H1 | 意味ではなくバイト階級 | **部分的** — `Spearman(3バイト系か, 中層比) = −0.50`。近義語4ペア中3ペアで4バイト側が上（中央値 1.26×）。例外は抽象ペア |

**⚠️ これは上記「深掘り診断」§3 を覆す。** 19体に広げると中層比は
**連続体**（2.71 → 5.66、最大ギャップ 0.73）であって明快な二分ではない。
あの二分は「中間例を含まない13体パネル」の性質だった。二値ラベル自体も
この問いには不適切で、*最終層*の値に支配され、☕（中層2.87）を 🚢（中層3.72）
より上に置いてしまう。追試では一貫して絶対中層比を用いている。

**残った一番の謎。** 🐈（3.96）も 🐱（3.95）も中層に噛むのに、🐈‍⬛（3.09）だけが
噛まず、⬛（3.00）にぴたりと着地する — しかも*方向*は猫のままで、モデルは
「黒猫」と正しく命名する。**方向の類似性と因果的効力が乖離している。**
ZWJ合成が何を損なっているにせよ、「方向が末尾成分に置き換わる」ではない。
次の一手は、ラッパーの `last_nonpad` だけでなく 🐈‍⬛ の**トークン位置ごと**に
方向を取り、どこで効力が失われるかを特定すること。

副産物2つ: 「感情だから平坦」では**ない**（😢 4.22 と 😭 4.19 は中層ピーク、
🥺 2.71 と 🤔 2.76 は平坦 — 同一ファミリー内で1.6倍の開き）。
トークン数でも**ない**（Spearman = −0.02）。

## 合成 — 2つのグリフをくっつけると何が起きるか

平坦グリフ追試が残した謎（🐈 3.96・🐱 3.95 は中層に噛むのに、ZWJ合成 🐈‍⬛ 3.09 は噛まない）
を3ランで追った。うち1つは**事前登録済み**。全数値は
[`results/composition_report.md`](results/composition_report.md)、事前登録は
[`PREREGISTRATION_mean_rule.md`](PREREGISTRATION_mean_rule.md)。

🐈‍⬛ は「🐈のトークン + ZWJ + ⬛のトークン」に厳密に分解されるので、
接合子の除去と順序の反転を独立に操作できる。

| | 判定 |
|---|---|
| **ZWJ接合子** | **これが効力を奪っているのではない。** 除去しても 🐈⬛ は 3.31 で、🐈 の 3.96 には戻らない。ただし*無効果ではない* — 値を 0.006〜0.215 動かす。「👩‍💻 3.39 対 👩💻 3.39 で完全同値」は2桁表示の産物だった（実際は 3.3933 対 3.3870）|
| **「最後の成分が支配」** | **否。** 順序は値を動かす（🐈⬛ 3.31 → ⬛🐈 3.61）が、**大きさも符号も一貫しない**: 強い成分を最後に置く方が高いのは、ある標本で7家族中6、次の標本では6家族中2。プールして 8/13（偶然は 6.5）|
| **順序効果 ∝ 成分差** | **そんな関係は存在しない。** 7家族で Spearman **+0.04**、別の6家族で **−0.94**。同一プロトコルで符号が反転する統計量はノイズである |
| **合成値を決めるもの** | **成分の平均。** `合成 ≈ 0.70 × 平均 + 1.16`。🐈‍⬛ が弱いのは単に 🐈(3.96) と ⬛(3.00) の平均が 3.48 だから |
| **方向 vs 効力** | **独立。** 26ケースで、順序反転による余弦の変化は最大 **0.09**、効力の変化は最大 **0.94** |

**平均則は事後解析で見つけた**（順序仮説が失敗した後）。だから6家族分の予測と
二部構成の判定基準を書き、**検定スクリプトが存在する前に**コミットし
（実行時にスクリプトが予測値を照合し、食い違えば中断する）、
その後で「平均則を形作っていない6家族」で検定した:

| 基準 | 要求 | 観測 | |
|---|---|---|---|
| Spearman(予測, 観測) | ≥ 0.70 | **+0.886** | PASS |
| 平均絶対誤差 | ≤ 0.72 | **0.308** | PASS |

成分11体すべてが過去測定値を再現した。ただし分解能に注意 — 過去値は2桁保存なので、
再現に成功する限り誤差は**構造上** 0.005 未満になる。これはそれより大きいドリフトを
検出する検査であって、4桁の一致ではない。

**より信頼できるのは否定的結果の方である。** 順序効果は、成分差との相関
（+0.04 → −0.94）も、自身の符号（6/7 → 2/6）も、同一プロトコルの2標本間で反転した。
これは n≈6 の統計量がここでは不安定であることの直接的な実証であり、
事前登録を通った平均則にも同じく当てはまる。堅いのは「接合子では合成の弱さを
説明できない」ことと、方向／効力の独立性（26ケース）である。

## 逆符号の1家族を追って、規則は見つからなかった

合成レポートが残した逆走家族（🍕⬛ 4.94 対 ⬛🍕 4.00、順序効果 **−0.94**）について、
「説明すべき対象が実在するか」「それは一般化するか」を2ランで確かめた。
全数値は [`results/order_report.md`](results/order_report.md)。

方法上の注記: ヌルの再シードでは検定にならない。注入KLは決定論的で、ヌルは
**両順序が共有する分母**にしか入らないため、再シードは順序効果を定数倍するだけで
符号を動かせない。実際の標本変動が入るのは方向推定と読み出しなので、そちらを変えた —
抽出ラッパーと注入ターゲットで 2×2 = 各ペア4つの独立推定。

| パネル | 事前に述べた予測 | 結果 |
|---|---|---|
| 🍕⬛ の符号は残るか | 安定**しない**だろう | **予測は誤り。** 🍕⬛ は4条件すべてで負（0/4）、🍔⬛ も一致（0/4）。🚗⬛ と 🍕⬜ は反転 |
| 「食べ物＋黒四角」は型か | 型なら新食べ物3つは負、非食べ物対照2つはそうならない | **型ではない。** 🍣⬛ は*逆向き*に安定（4/4陽性）、🍜⬛ 2/4・🍺⬛ 1/4 は反転。非食べ物対照 🐶⬛・🌈⬛ も3/4で反転し、食べ物と区別できない |

個別のペアは再現性のある順序選好を持ちうるが、それは**成分差にも、意味カテゴリにも、
同一カテゴリの他メンバーにも従わない** — そして非食べ物ペアも同様に安定しうる。
🍕⬛ と 🍔⬛ が持つものが何であれ、食べ物では予測できない。
一般則は残らず、大きさも安定しない（🍕⬛ は −1.09〜−0.03）。保存されるのは符号だけ。

**訂正。** 本節の初版は「対照は3/4で反転、食べ物と区別できない」と述べていた。
これは条件ループ内で*強い成分*を再判定していた実装に由来し、⬛ が相方を上回る条件の
セルが鏡像の枠で測られていたためである。基準を固定すると対照は両方とも符号安定である。
結論は変わらないが、理由が異なる。

明記しておくべき点: 「4条件で安定」は弱い基準である。符号が真に五分五分なら
8ペアに1つは偶然そう見え、ここでは9ペアを検定している。

## これは何でないか

- 封印済み v2 実験**ではなく**、その再現でもない。
- 因果的・意味論的主張**ではない**。レコードには
  `pre-causal-activation-screen`、`causal_claim_authorized: false` が刻印されている。
- トークナイザ非依存性の結果**ではない**。トークン数は matched 階層*内で統制*され、
  ladder 階層で*測定*されている。これは封印済み研究の `wrapper_tokenization_control`
  HOLD より大幅に強いが、依然として1パネル・1モデル・1位置（`last_nonpad`）・3ターゲットに限られる。
- 正準な来歴**ではない**。凍結外のライブラリ版と `orjson` 代替を用いているため、
  ここで出るレシートハッシュは正準実行と比較できない。

## 環境と来歴

- **重みは封印済み v2 アーティファクトと同一** — `mlx-community/Llama-3.2-3B-bf16`
  @ `60a99aaf…`、`manifest_sha256 dc5b61a2c4aa123f82e7d0471b4cdb3a7d8de3b6a8db327047fb1b6d05e3bdf4`。
  姉妹 sandbox の `verify_bf16.py` で検証済み。
- Python 3.12.6 / torch 2.12.1 / transformers 5.13.0 / numpy 2.2.3
  （凍結は 3.13.13 / 2.11.0 / 4.57.6 / 2.4.4 — ゆえに v2 再現ではない）。
- シムは `../llama32_3b_bf16_ooc_screen_v1/scripts/shim/` を `PYTHONPATH` 経由でのみ再利用。
  ディスク上のものには一切パッチを当てない。
- `PYTHONNOUSERSITE=1` によりマシンのユーザーサイト numpy/torch モンキーパッチ層を無効化。
  数値は未パッチ。
- **数値に関する注記。** macOS/Accelerate 上の numpy は、大きな float64 内積で
  `divide by zero / overflow / invalid value encountered in matmul` の
  RuntimeWarning を偽陽性で出す。本データについて偽陽性であることを検証済み:
  活性とロジットはすべて有限であり、`a @ b` は純 Python 総和と**ビット一致**する
  （相対誤差は厳密に 0.0）。当該メッセージのみをフィルタしている。
