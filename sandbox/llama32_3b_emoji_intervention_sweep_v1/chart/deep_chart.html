Does the emoji-direction effect survive more targets and a bigger null?

The first sweep could only say the magnitude-controlled push was clean on one of three targets, against 24 random directions. This run takes the focused panel to 12 targets and 256 random directions each, then reads the layer profile and the specificity off the same weights.

Out of contract. Exploratory sandbox run on the real bf16 weights. Not the sealed v2 experiment, no causal or semantic claim (pre-causal-activation-screen). No holdout bank is used.

1 · It generalises — and detectability belongs to the target, not the glyph

Ratio to the null median per cell; bold = none of the 256 random directions reached it (p = 0.0039, the floor). Targets are ordered by baseline entropy. Spearman(entropy, number of glyphs clearing the null) = +0.70 — sharp factual prompts hide the effect because a random push moves them a lot too.

13 glyphs × 12 targets at L16, α=0.5. The weak controls (⬛ 🥺 ⛵) clear the null on just as many targets as the strong glyphs — the binary test saturates, so the ranking has to be read from the ratio, not from significance.
Every layer 0..27, mean over 3 targets. Peak layer median = L16. Dashed line = parity with the null median. sweep_v1 only sampled L5/L11/L16.

3 · What the direction is specific to

Mean logit delta on each hand-specified probe group when a glyph's own direction is injected (rows). Probe words were written by hand, not harvested from the model's own top-boosted lists, so the diagonal is not selected-on. Own probe group is largest for 4/13 glyphs; own category block is largest for 10/13.

What this does not show. A pre-causal activation screen. The random-direction null is a size control, not a semantic control. Beating it means a direction is structured, not that the structure is meaning.
